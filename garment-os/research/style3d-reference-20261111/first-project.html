首个工程文件完整工作流

准备工作

  • 已安装 Style3D Studio（推荐 V8.0 及以上版本）
  • 已登录账号，且本机内存 ≥ 8GB（模拟需要空闲内存 ≥ 1GB）
  • 准备一份 DXF 版片文件（来自 ET、富怡、力克、格博等 CAD 软件均可）
� 提示：如果暂时没有 DXF，可在 Studio 资源库中下载示例工程的版片；本教程默认以一份基础短袖 T 恤的 DXF 为例。

界面速览

Studio 工作区主要由三部分组成：
  • 左侧 2D 窗口 — 显示版片，用于编辑形状、缝纫线
  • 右侧 3D 窗口 — 显示穿着在模特上的服装，进行模拟与渲染
  • 顶部工具栏 — 文件、开始（编辑工具）、素材等
▲ 顶部工具栏 - 开始栏工具一
▲ 2D 窗口：版片编辑区
▲ 3D 窗口：模特与服装预览

步骤一：新建工程

  1. 打开 Studio 后，会自动创建一个空白工程。
▲ 打开后的空白工程
  1. 如当前已有工程文件，则需手动新建：
    1) 点击顶部菜单【文件】▶【新建】
    2) 在弹出的提示中选择是否保存当前的旧工程文件
    3) 新建完成后，3D 窗口会显示模特，2D 窗口为空
� 提示：模特可后续从资源库中替换。
▲ 资源库替换模特操作

步骤二：导入 DXF 版片

操作路径

  1. 顶部菜单【文件】▶【导入】▶【导入 DXF文件】（或直接将 DXF 文件拖入 2D 窗口）
  2. 在导入选项弹窗中确认：单位（毫米/英寸）、是否导入版片缝边、是否反转布纹线等
  3. 点击【确定】，版片即出现在 2D 窗口中
▲ 资源库替换模特操作

常见问题

  • 版片轮廓变形 → 检查 CAD 端是否使用了样条曲线；建议先将曲线转为多段线再导出
  • 版片包含多余缝头 → 导入选项中取消勾选「保留缝份」，或在版片属性中手动调整
  • 版片有缺失 → 通常是 DXF 中部分图层未被识别，回到 CAD 检查图层命名与版片闭合

步骤三：缝制（缝纫与安排）

缝纫的本质是告诉软件「哪条边和哪条边在模拟时要缝在一起」。Studio 提供 4 种缝纫方式：线缝纫、自由缝纫、多段线缝纫、多段自由缝纫。新手最常用前两种。

3.1 安排版片到模特

版片刚导入时是平铺的，需要先「安排」到模特身上的大致位置：
  1. 在 3D 窗口打开【显示安排点】（小蓝点会浮现在模特周围）
  2. 在 2D 窗口选中版片 → 点击 3D 窗口对应位置的安排点
  3. 前片→ 胸前安排点；后片 → 背部安排点；袖片 → 手臂安排点
  4. 重复直到所有版片都安排完毕
▲ 安排版片到模特操作示意

3.2 设置缝纫线

  1. 在 2D 窗口先点击第一条要线的起点，再点击这条线的终点（注意箭头方向，代表缝合的起止）
  2. 再点击第二条要缝合的边的起点和终点（按住shift可依次选择多条），两条边即被关联为一组缝纫线
  3. 重复操作，直到所有需要缝合的边都连好
▲ 调换缝纫线操作示意
� 提示：缝纫线的方向必须一致，否则模拟后会出现拧麻花。如方向错了，右键缝纫线 ▶ 调换缝纫线。
▲ 设置缝纫线操作示意

步骤四：模拟

模拟（Simulation）是 Style3D 的核心功能——它会让安排好的版片按照缝纫关系真实地「穿」到模特身上。

启动模拟

  1. 确认所有版片都已安排在模特周围（不要重叠或穿透模特）
  2. 点击 3D 窗口顶部的【模拟】按钮（或快捷键 空格键）
  3. 观察服装逐渐贴合模特，等待形态稳定后再次点击【模拟】停止
▲ 3D 窗口顶部 - 模拟按钮区域
▲ 设置缝纫线操作示意

模拟调优

  • 第一次模拟建议粒子间距设为 15–20mm，快速看整体效果
  • 形态基本正确后，调低到 5–10mm 并开启【精确模拟】，获取真实褶皱
  • 如遇版片穿透，暂停模拟 → 手动把穿透版片往外拖 → 重新启动
  • 提示「模拟被终止 / illegal memory access」→ 通常是显存不足，关闭多余软件再试

步骤五：保存与导出

5.1 保存工程

  1. 【文件】▶【保存项目】（Ctrl/Cmd + S），文件后缀 .sproj
  2. 首次保存会自动生成预览图；系统会自动截取当前 3D 视窗的画面作为项目预览图，并随 .sproj 工程文件一同保存。该预览图将用于文件浏览器或资源库中快速识别项目内容。
� 提示：Studio 默认开启自动保存。如软件闪退，到自动保存目录（偏好设置中查看路径）可找回。

5.2 导出 3D 模型

根据下游用途选择格式：
  • OBJ — 通用 3D 格式，适合 C4D / Blender / 3ds Max 做后续渲染
  • FBX — 带骨骼与动画，适合游戏引擎（Unity / Unreal Engine）
  • GLB / GLTF — 网页与移动端展示首选，体积小、加载快
  • U3D / PDF — 客户预览与设计沟通
    操作路径：【文件】▶【导出】▶ 选择目标格式 ▶ 确认坐标系、单位、是否合并贴图等选项 ▶ 点击【导出】。
    � 提示：导出 FBX 时人台变得很小？通常是单位不匹配——勾选「单位：m」或在接收端调整缩放即可。

    5.3 导出 2D 工艺资料

    如果还需要给打版师反馈修改后的版片：
  • 【文件】▶【导出】▶【导出 DXF】— 输出修改后的纸样
  • 【工具】▶【2D版片快照】▶【导出 PDF/PSD/PNG等】— 2D 快照，含尺寸标注与缝纫线
▲ 2D版片快照工具
▲ 导出 PDF/PSD/PNG等操作示意

流程总结

把以上五步浓缩成一句话备忘：
新建工程 → 拖入 DXF → 连缝纫线 → 安排到模特 → 按空格模拟 → Ctrl+S 保存 → 导出
跑通一次完整链路后，再去深入每一步的高级技巧（精确模拟、明线设置、面料属性、放码、渲染出图），学习曲线会平缓很多。祝你上手愉快！
