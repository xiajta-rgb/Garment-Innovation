Rendering Thickness
Set the rendering thickness for the patterns. Rendering thickness value is only visible and does not Simulate as the thickness value space out between Fabrics. Select the pattern to set the rendering thickness. * To see the rendering thickness, 3D Garment Rendering Style must be set to one of the thick-surface styles. Set the thickness options in Property Editor. Option Description Add'l Thickness - Rendering Enter desired rendering thickness value. This value is for rendering purposes only and does not affect collisions. However, when exporting, enabling the Thick option will export both the Side and Back Mesh and UVs ✨Tip: Collision thickness can be adjusted at [Simation Properties ▶ Add'l Thickness - Collision]. Extrusion Direction Specify the direction in which thickness is applied based on the Pattern Plane. Both Apply thickness evenly to both the front and back based on the Pattern. Forward Apply thickness forward. Backward Apply thickness backward. Toggle each side on or off to determine whether to generate the Mesh. Front Face Specify whether to generate the Front Face. Back Face Specify whether to generate the Back Face. Seam Face Specify whether to generate the surface where the stitched and bonded parts meet. Side Geometry Curvature (%) Specify the curvature. Resolution Set the number of subdivisions. Doubled Sided Apply the same curve to both sides. UV Expansion Watch Video The side and back UVs can be edited in UV Editor . Back Face Switch the UV from the front to the back. Side Face Expand the UVs to include the side.
