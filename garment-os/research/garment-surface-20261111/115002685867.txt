Adjust Rendering Thickness 
List of Contents Fabric Unit Pattern Unit Objective Set Fabric thickness for a Garment in the 3D Garment window. Rendering thickness from the center of the Garment is set for 0.5mm as default vale, and it is adjustable. This thickness value is only visible and does not Simulate as the thickness value space out between Fabrics. ※ Note: To see the rendering thickness, 3D Garment Rendering Style must be set on Thick Textured Surface . Location Fabric Unit Object Browser ▶ Fabric ▶ Fabric Item ▶Property Editor ▶ Thickness Pattern Unit (ver2.3.0) Select Pattern in 2D/3D Window ▶ Property Editor ▶ Simulation Properties ▶ Add'l Thickness-Rendering Operation Fabric Unit Follow the indicated guideline below: Object Browser ▶ Fabric ▶ Fabric Item ▶Property Editor ▶ Thickness Enter desired rendering thickness value. →The thickness is now being adjusted and applied. Pattern Unit (ver2.3.0) Follow the indicated guideline below: Select Pattern in 2D/3D Window ▶ Property Editor ▶ Simulation Properties ▶ Add'l Thickness-Rendering Enter desired rendering thickness value. →The thickness is now being adjusted and applied.
