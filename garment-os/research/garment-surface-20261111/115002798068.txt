Adjust Collision Thickness
Simulation thickness is invisible set property that represents the collision limit for Garments to result smooth Simulation. 📝 Note: For the same reason, the default value of Avatar thickness (Skin Offset) is set for 3mm. For form-fitting Garments or accurate fitting measurement, it is recommended that Skin Offset is adjusted alongside the Simulation thickness. Select Pattern in 2D/3D Window ▶ Property Editor ▶ Simulation Properties ▶ Add'l Thickness-Collision Enter desired rendering thickness value. →The thickness is now being adjusted and applied. Collision Thickness has been improved so that its thickness direction matches Rendering Thickness , ensuring that the visible thickness and simulation collision are applied consistently.
