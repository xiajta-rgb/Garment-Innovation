Add Pattern Thickness
Objective Extrude garment to express thickness. (These settings will apply to mesh export when using Thick export option, or use for 3D display only). Location 2D Toolbar ▶ Edit Pattern / Transform Pattern 3D Window ▶ Garment Display Option ▶ Wireframe on Monochrome (Thick) (ver. 2024.2) Operation (ver. 2024.2) Follow the guideline below to set Garment Display Option to Wireframe on Monochrome (Thick). 3D Window ▶ Garment Display Option ▶ Wireframe on Monochrome (Thick) Follow the indicated guideline below: 2D Toolbar ▶ Edit Pattern / Transform Pattern Select a Pattern or Pattern line to express doubled sided effect. → Its properties appear in the Property Editor. Property Editor ▶ Geometry → Modifies the Geometry Properties which will affect mesh style / extrusion direction when exporting with thickness. Geometry Properties Add'l Thickness - Rendering (mm) Displays the added thickness in addition to the Thickness value of Fabric Style. Extrusion Direction Sets the direction to display the thickness. Both Apply the thickness front/rear around the pattern. Forward Apply the thickness in the front direction of the pattern. Backward Apply the thickness in the rear direction of the pattern. Toggle each side on or off to determine whether to generate the Mesh. (ver. 2025.0) Front Face Set whether or not the front part is displayed based on the normal direction. Back Face Set whether or not the back part is displayed based on the normal direction. Seam Face Set whether or not to show overlapping sides on the sewn line. Side Geometry Curvature (%) Set side geometry lateral curvature percentage. Resolution Set divisions for the side mesh. Double Side Apply Curvature attribute values to both front and back symmetrical from the pattern. UV Expansion (ver. 2025.0) The Side and Back UVs can be edited in UV Editor. Video here Back Face Check this on to show the back face UV. Side Face Check this on to show the side thickness UV. Mesh Style Triangle Re-mesh the pattern using triangular mesh option Quad (Optimized) Re-mesh the pattern using quadrangular mesh option. Generates aligned automatic Retopology results. Quad (Grid) Re-mesh the pattern using quadrangular mesh option. Generates pattern with a uniform grid. Face Count Display total face count of the pattern. Vertex Count Display total vertex count of the pattern. ※ Note: To use UV Expansion, Thick Textured surface must be active in the 3D window. Operation (Ver. 2024.1 and below) Follow the indicated guideline below: 2D Toolbar ▶ Edit Pattern / Transform Pattern Select a Pattern or Pattern line to express doubled sided effect. → Its properties appear in the Property Editor. Property Editor ▶ Selected Line ▶ Curved Side Geometry ▶ Check on Double Sided → The selected Pattern or Pattern line is now being displayed as double sided.
