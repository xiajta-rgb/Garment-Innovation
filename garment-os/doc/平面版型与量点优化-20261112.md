# 平面版型与量点优化

日期：2026-11-12。范围：原设计台中的 Teagan 圆领装袖 T 恤及其定制矩阵预览。

## 本次修改

- 正背衣身直接展开同一组源净样，保留三次曲线；不再用组装投影宽度表达平铺胸宽。源裁片及毫米裁片导出未重画。
- 袖子使用源袖中净长和缝合后袖口平宽，摊示角度由源袖山高、上臂宽和衣身袖窿端点推导。袖窿连接使用源曲线，避免三角缺口。此为尺寸化款式示意，未验证袖山摊平的物理变形。
- 领圈按源领窝连续展开，领条为等宽平面示意；贴袋按源毫米位置保留。未把普通装袖画斜线当插肩。
- 新增14项源净样规格：前后衣长、前后胸宽、净胸围、胸围净松量、肩宽、前下摆宽、领窝宽、前后领深、袖窿深、袖中长、袖口平宽。每项列出测量基准及半围或整圈定义。
- A–E量点可显示或隐藏，可切换纯结构线；下载SVG、PNG使用当前显示稿。原有组装三视图保留为可展开对照。
- 矩阵沿用相同绘图和规格；当前比较组预先取统一尺度，避免逐款自动放大后掩盖真实比例差异。
- 森灵提示词加入本组净样长度、胸宽、肩宽、袖长和袖口比例。本轮未执行付费生成。

## 实际核验

浏览器记录：[browser.json](evidence/flat-proportions-20261112/browser.json)。

在原工作台实际创建T恤、输入衣长、改松量、改袖片、切换结构线与量点、下载SVG并进入矩阵。检查图形路径、规格、导出内容及矩阵统一尺度，同时在1294×1147视窗检查页面宽度。

同款基准输入衣长600 mm，拓领后新肩颈点前后净衣长为589.9 mm。输入基准取原源HPS；UI已解释两种基准，不能把输入衣长与拓领后的实物肩颈点衣长混称。

将输入衣长增加40 mm后，前后实际净衣长均增加40 mm；由于源侧缝曲线随衣长重算，胸宽约有0.18 mm联动，不宣称胸宽严格不变。袖片不随衣身纵向拉伸。

三种参考尺码（XS、M、XXXL）×三种松量×三种袖长，共27组、54个正背图的袖长和袖口几何检查；源量点缺失或非有限数值时阻止推算。

全量检查通过：67个测试文件、1275项测试通过，构建、代码检查及架构检查通过。构建仍有原有的大包体积提示。浏览器6组流程通过，无页面异常。汇总见 [verification.json](evidence/flat-proportions-20261112/verification.json)。

## 适用边界

这些是源净样尺寸和款式平铺示意，不是成品洗后实测。侧面继续标为未校准体积参考，不承担平铺胸宽或真实垂坠的证明。领条缩率、材质回弹、缩水率、试衣、袖山摊平及生产工艺仍需实样验证。
