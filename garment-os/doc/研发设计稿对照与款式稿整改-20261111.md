# 研发设计稿对照与款式稿整改

已按照用户指定的研发货盘实际图稿，整改圆领短袖和长袖的表达。当前交付是款式、工艺与源裁片关联的设计示意；实页外观及物理试衣未验收。

## 一、实际参考

来源：[研发货盘数据源](https://xcnplmqtjyqc.feishu.cn/wiki/IFexwA30piTbkFkjwl9cn77pnKg?table=tbl3lvwyeOg7DpYT&view=vewzEmT3cb)。实时解析目标为`研发货盘数据源_20261110`，指定视图记录已读完。设计稿字段实际为文本图片URL，并非附件。仅做读取，未改写飞书。

已查看8款真实图样：LT24M1204、L23M951D、COT25M002、L23M948D、AT25M3295、AT25M3288、L21M445、LT26M1581。其中包含款式图、配色表和实物批版图，不能将8张都称为三视图。COT25M002和LT26M1581主要提供前后图及工艺标注，并无侧视。

下载图、记录ID、原URL和SHA256保存在`research/rd-design-reference-20261111/samples.json`。本轮对照脚本逐张重新核对8张图片的指纹。

| 样本 | 原图可确认的表达与参数 | 当前采用方式 |
|---|---|---|
| COT25M002 微落肩短T | 自然短袖；实线外轮廓、装袖线；领高17.5mm、1×1罗纹；袖口与下摆20mm坎车双压线；后领10mm本布包边 | 采用前后图、自然袖姿、分层线宽、罗纹方向纹、双针和引线标注的表达规则 |
| LT26M1581 圆领长T | 前后图；一袖弯折作排版；领宽18mm；后领包边8mm；袖口/下摆折深23mm、双线间距6mm | 当前长袖用对称自然下垂姿态；工艺数值仍取当前编辑参数，不将该款参数覆盖全部模板 |
| AT25M3295 / AT25M3288 | 肩袖分界清楚；袖口/下摆55mm独立罗纹；圆领/帽、绳、袋鼠袋各有表达 | 作为后续卫衣完成态的参考；本轮没有将卫衣组装冒充已完成 |

COT25M002原稿还明确写有“尺码尚未确认”。这些是具体款的设计资料，不是所有服装的强制尺寸标准。图中FC304、FC-00332等材料也未自动复制为本系统默认材料。

## 二、已修正的对应关系

| 原问题 | 当前行为 | 依据与限制 |
|---|---|---|
| 躯干圆截面压窄正面、肩部深度线性从零增长形成侧视尖顶 | 浅椭圆支撑、圆肩过渡；前后同一模型 | 支撑比例属于示意姿态设定，不是人体测量或行业标准 |
| 长短袖一律外张 | 长袖向下68°、短袖向下48°的初始支撑，再执行共缝约束 | 角度是可视化姿态，不修改袖片CAD或袖长 |
| 圆领前缘偏尖；直接圆圈平滑又会把前领抬高 | 分别保留源姿态的前后领深，使用连续圆领支撑，再生成实体领条 | 仅适用于当前已经接通的圆领/挖领模板；没有将V领套入圆领 |
| 三角面碎边、断续结构线直接进入设计稿 | 深度测试得到可见区域，生成连续外轮廓；结构缝、双针、罗纹分层 | 边缘平滑只作用于屏幕轮廓，不反写毫米数据 |
| 小图难检查、工艺数值没有清楚的对应点 | 增加“前后款式稿”，可放大、下载SVG；引线锚点取实际可见工艺路径 | 标注随领宽、折深、双针间距更新；关闭工艺后不留虚假的工艺标注 |

前后设计稿及正背侧检查图使用同一完成态模型、统一比例尺与遮挡规则。没有另画一个与三维无关的服装轮廓。侧面明确标作“组装参考”，不冒称原图已经提供标准侧视。

当前示例默认领宽18mm、袖口折深20mm、下摆折深25mm、双针间距4mm，和COT25M002的具体工艺并不全部相等。对照结论是表达规则已建立对应，不能据此宣称“同款、同尺寸、一比一生产复现”。

## 三、页面入口

打开[本地系统](http://localhost:5341/)，进入“3D 映射 → 三维成衣”，点击工具栏“前后款式稿”，或右下角“放大前后款式稿”。弹窗支持滚动查看、下载SVG、关闭和Esc退出。原正背侧小图仍可以联动主相机。

罗纹方向纹由领条实际几何生成，工艺引线带有对应路径身份。面料底色和印花目前在三维中预览，白底款式稿用于看清结构与工艺，不冒充完整带色技术包。

## 四、验证与真实图证

另运行当前正式构建中的后台计算：7款裁片映射通过，待重建V领按预期拒绝；Brian、短袖和背心成衣通过，卫衣完成态按预期拒绝。报告分别在本轮证据目录的`mesh-worker/`、`garment-worker/`中。这是原生子线程重放，不是浏览器运行证据。

## 五、尚未达到的部分

当前短袖、Brian示例整形相对源配缝姿态最大移动分别约22.5mm、24.4mm。它们反映示意调整，不能当作制造公差；源CAD尺寸保持独立。默认约9.5万显示三角面、按源对象与设置缓存；本轮没有测量真实浏览器帧率。

后领本布包边、商标工艺、实际材料身份、经测试的领条长度比例、人体/布料碰撞和物理垂坠仍未完成。卫衣、衬衫完成态和背心包条也仍待规则。`materialValidated`、`drapeValidated`、`productionApproved`保持false。当前结果可以继续讨论款式和工艺关联，尚不能作为实物一致性或正式生产验收结论。
