# 服装造型域：主档与制图系统的协同约定

本系统负责服装结构、版型及裁片的参数化表达。洞察数据库沉淀可复用的造型主档与参数口径，GarmentOS 按指定版本和实际输入生成几何，两者通过稳定来源标识关联。

## 一、造型资产的层级

| 对象 | 对应元素类型 / 资产粒度 | 管理内容 | 关系与使用边界 |
|---|---|---|---|
| 版型模板 | 版型模板 / 组合模板 | 适用体型与产品范围、制图方法和版本、所需参数、部件组合 | “组成元素”引用结构部件。不能把模板登记当作具体裁片验收 |
| 结构部件 | 结构部件模板 / 部件规则 | 衣身、袖、领、袖口、门襟、口袋的构型、生成规则和输出角色 | 一条规则可输出多个片型，例如衣身部件输出前身与后身 |
| 尺寸裁片 | 纸样与裁片 / 单片实例 | 一次明确输入下的净样、毛样、尺寸、数量、对折与镜像等 | “生成依据”引用实际使用的模板和部件；参数/路径变化形成新版本 |
| 廓形配置 | 廓形模板 / 松量配置 | 适用方法、松量模式、数值与单位 | 比例松量与毫米松量分别定义；不同方法的“合身”不能互换 |
| 技术图及参考 | 款式技术图等 | 观察到的外观、结构参考及来源 | 缺少可核对几何时只能用于设计参考 |

色彩、图案、面料、辅料和工艺是配套引用。材料厚度、伸长/回缩、缩水及工艺条件会影响制版，必须有证据后才能认定兼容；屏幕色和演示面料不能替代实物标准。

## 二、数据库保持两张核心表

1. **服装元素素材库**保存元素主档。继续使用元素域、类型、粒度、产品核、部位、对象层位、来源/版本、规格信息、标签、状态、权利和缺失项。
2. **制版参数定义**保存稳定参数编码、人体/设计/接口/工艺量角色、类型、单位、量取基准、条件与复核状态。同一参数复用同一条定义，实例取值不写回定义表。
3. **组成元素**表示向下的部件组成；**生成依据**表示裁片向上的生成来源。两者各司其职，避免把模板错误地当作裁片的组成部分。
4. **规格信息**只保存可复用的关键配置或裁片的紧凑输入快照。完整路径、控制点和制图检查留在本地裁片包，不再建立日志编号表或重复规范表。
5. **标准标签候选**继续关联洞察库现有标准标签字典。元素类型、部位是管理分类；正式标签编码及字典版本须核验后填写。未确认的对应关系留空，不按相似名称自动合并。
6. **适用产品核**与**产品主档**只在具有对应事实时关联。男装参考基型不会自动等于所有上衣产品核；不凭参考图推断材料或成品适用性。

入口：[服装造型库](https://xcnplmqtjyqc.feishu.cn/wiki/BBbgwcqBFi3oIakFo19csZETnTy?table=tblI4uKwuTbKFFeT&view=vewlxhSksa)。其他域保留配套视图。

## 三、当前可衔接的参考范围

当前有5个可生成参考模板，均固定FreeSewing 4.10.2：Brian基础版型、Teagan基础/收腰两种短袖配置、Sven无罗纹长袖、Simon完整男装衬衫。新增方法共16条部件规则，通过父模板保留完整解算上下文；各方法不能任意混拼。逐项处置及未重建模板见[全模板审查与重建报告](全模板审查与重建报告-20261110.md)。它们均不是制造认证，也不代表女装梭织省道体系。

Brian的12个实际输入必须逐项绑定；新增参考还绑定腰围 `waistCircumference` 与臀围 `hipCircumference`：

| 系统输入 | 参数定义编码 | 上游含义 / 单位 |
|---|---|---|
| 胸围 | chestCircumference | chest / mm |
| 颈围 | neckCircumference | neck / mm |
| 总肩宽 | shoulderToShoulder | shoulderToShoulder / mm，不是单肩肩长 |
| 肩斜角 | shoulderSlope | shoulderSlope / deg |
| HPS→胸围线 | hpsToBust | hpsToBust / mm，不是颈肩点至胸点 |
| HPS→后腰 | hpsToWaistBack | hpsToWaistBack / mm，不是后颈点背长 |
| 腰→腋下 | waistToArmpit | waistToArmpit / mm |
| 腰→臀线 | waistToHips | waistToHips / mm |
| HPS→下摆 | hpsToHem | mm；换算 lengthBonus = 衣长 / (后腰长 + 腰臀距) − 1 |
| 上臂围 | upperArmCircumference | biceps / mm |
| 肩端→腕 | shoulderToWrist | shoulderToWrist / mm，不是任意成品袖长 |
| 腕围 | wristCircumference | wrist / mm |

另绑定胸围松量比例 chestEaseRatio、上臂松量比例 bicepsEaseRatio 和参考制图缝份 referenceSeamAllowance。例如 0.15 表示增加15%，不能作为15mm解释。三种松量方案放在当前 Brian 模板的规格中，避免误用旧的绝对毫米松量配置。

来源缺失、素材隔离/弃用、版本不兼容、参数缺失或单位/角色不一致时禁止候选导出。缺值不填0，不用近似同名参数替代。参考缝份允许0～30mm、默认10mm，仅为项目参考设置。

## 四、同步与沉淀流程

1. 维护飞书主档与参数定义，完成来源和分类核对。
2. 通过 `python scripts/sync-shape-library.py` 全量分页读取两表，检查唯一来源标识、关联、组成循环与规格格式；通过后原子替换应用快照。前端明确显示“飞书快照”，不是实时双向同步。没有把飞书凭据交给浏览器。
3. 系统生成尺寸裁片。目前仅Brian接通2.0候选包，包含12项输入、15项参数定义的本地冻结快照、模板/部件来源、实际净/毛样路径、控制点、逐边标识、布纹/剪口、坐标单位和几何检查。Teagan/Sven/Simon主档已关联；具体尺寸候选登记协议尚待扩展，当前可保存设计、导出完整输入配置和整幅参考SVG。
4. 裁片版本按输入、参考版本、参数语义与路径内容形成稳定指纹。相同内容重复导出保持同一版本，改变尺寸/路径产生新版本；不会再用日期作为未保存设计的唯一标识。
5. `python scripts/import-design-registrations.py --file <候选包>` 先生成只读计划，核对实时主档与冻结参数语义。加 `--apply` 才创建缺失候选。先验证所有包，再分批创建、逐字段读回，成功后回写本地记录映射。已存在版本保留人工状态/标签，内容冲突则停止。
6. 导入后重新读取快照，应用即可按类型、部位、名称筛选新裁片。旧1.0包必须从当前参考重新生成；旧静态种子入口已退役。

候选包保存在用户下载位置，数据库只接收紧凑业务规格和来源关系。本轮用于验证的参考包仅作本地预检，没有把测试裁片写入业务库。

## 五、进入制造前还必须补齐

1. 实测对象与测量协议、适用体型、具体尺码与放码规则；当前输入明确标为待核验快照。
2. 各部件构型及有效参数域、独立参考图纸、连接边配对、走缝目标、公差及吃势分配。
3. 逐边缝份、折边/翻折、剪口工艺与布纹方向、裁剪层/数量/镜像、材料版本与缩率。
4. 毛样面积、排料效率、生产用量及完整BOM。当前毛样用量与制造级缝合配对保持未知。
5. 领、袖口、门襟、口袋等专业构型的独立核验，女装胸省/省道转移等适用方法。
6. 专业复核、试坯试穿、材料/工艺验证及人工生产批准。几何一致、测试通过、标签核验或许可核验中的任一项，都不能单独替代生产批准。
