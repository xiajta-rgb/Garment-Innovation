# 工作台UI逻辑审查

本轮围绕原工作台的实际操作完成审查与修复，覆盖设计台、资产库、裁片库、参考资料，以及定制矩阵、款式工作流、3D映射入口。设计方案的数据保留、当前操作目标、只读状态和键盘行为是主要检查内容。

## 已修复的问题

| 操作 | 原问题 | 当前行为 |
| --- | --- | --- |
| 顶部 Export | 组合设计中仍寻找旧画布，点击没有下载 | 导出当前页面的设计；空方案和比对状态提示先打开待导出方案。配套裁片页和工作流也接入各自导出入口 |
| 并排比对 | 右侧仍可直接编辑当前方案 | 侧栏仅保留说明和编辑入口，继续编辑后再修改 |
| 源净样预览 | Logo不可见，但仍保留编辑工具和裁片替换入口 | 作为只读参考展示；隐藏改款工具，禁用裁片替换与拖入，返回款式片后再编辑 |
| 口袋选择 | 再点同一袋型会重置尺寸、位置、角度 | 重复选择仅选中已有口袋；单双袋切换保留已有袋片 |
| 左侧颜色与面料 | 修改原始裁片设置，当前组合方案不变化 | 组合编辑时直接作用于当前方案；原始模板尺寸与方案尺寸的关系有明确说明 |
| 企业面料 | 应用目标不明确，资产库选料不能直接显示在组合方案 | 可明确选择当前方案或原始裁片资料；默认给非空方案套用来源照片，领口和袖口同步启用对应外观 |
| Logo文字 | 无法清空后整体替换 | 支持编辑草稿，失焦或Enter提交；空文字恢复已有内容 |
| 键盘与弹窗 | 输入时Ctrl+S未保存，弹窗可能触发底层撤销，Logo缺少方向键微调 | 保存前提交输入；弹窗保护底层状态；Logo支持方向键、Shift微调，元素标签支持方向键/Home/End |
| 超大或不可读面料图 | 套料失败后没有仅保留来源资料的选项 | 保留真实错误，允许显式选择“仅关联资料”，不会将资料关联标成照片套用成功 |
| 环境兼容 | 缺少ResizeObserver时画布报错 | 使用窗口尺寸监听作为后备方式，保持工作台可打开 |

点击画布空白可以取消选择；结构部位不再显示任意删除入口。Logo、口袋原有的旋转、缩放、Del删除、撤销、复制和导出继续通过回归检查。

## 浏览器验证范围

专项检查保存在 [ui-review-20261112](evidence/ui-review-20261112/)：19项流程，覆盖上述主要修复、全部一级导航和参考资料分类、各设计工具间切换后保留组合方案、亮暗主题、桌面1416×1147和移动390×844布局。另保留13项附件编辑、12项固定部位及13项改款元素回归记录。

最终完整检查通过：73个测试文件、1302项测试全部通过，架构检查、代码规范、类型检查及生产构建成功。四组浏览器回归合计57项流程通过，未发现页面运行错误。构建仍有部分资源包超过500kB的体积提示，未将其计为功能验收失败。

企业面料验证使用实际查询返回的 FC-00319“加厚26S精梳全棉平纹”，并核对照片嵌入当前方案。原始裁片目标不改变组合方案用料。照片异步返回时若设计或方案已切换，会拒绝应用到错误目标；失败照片及显式资料关联也有独立检查。

审查前的复现记录见 baseline.json；其中“新建设计仍停留在比对模式”的猜测未复现，未计为缺陷。最终19项流程再次验证了从比对新建后回到可编辑空方案。

## 证据与边界

- browser.json、findings.json：浏览器断言、实际请求范围和修复清单。
- design-desktop.png、design-dark.png、design-mobile.png：共享主题和布局。
- comparison-readonly.png、source-readonly.png：比对和来源预览的只读状态。
- asset-target.png、saved-composition.json、downloads/：面料目标、方案快照和实际下载。
- verification.json：最终检查结果。

本轮没有发起森灵生图或外部业务写入。UI检查不等于所有交互组合已穷尽，也不代表专业制版或样衣验收。面料照片的实际比例、颜色与物性仍以实样为准。后续已补齐[超大面料图自动压缩套用](超大面料自动压缩-20261112.md)，原12MB阻断问题已解决。3D和工作流本轮检查入口、切换与方案保留，未重新验收每种三维效果或生成模型输出。
