# 面料管理接入

## 一、工作台中的位置

入口为“资产库 → 面料库 → 面料管理”。沿用现有工作台主题、控件与排版，支持桌面与窄屏。原4份原稿材料保留在“原稿面料”，其参考母版应用范围和兼容检查继续保留。面料管理关联的是当前款式，不通过公司参考母版冒充同款材料。

可按面料编码、名称、分类、功能、启停状态、季节查询；更多条件含精确面料ID和防晒指数。默认只在用户点击查询时请求启用记录，每页25条，可选择50或100条。翻页只请求指定页，不自动枚举全量。

左侧列表、右侧明细与关联操作使用同一条来源记录。可以分别关联衣身主料、领口、袖口、下摆；新增关联要求来源明确启用且物料类型为面料，材料适配和物性仍需确认。选用后原工作台显示材料摘要，可返回管理页、解除、撤销/重做、保存并重新打开。新建设计清空已有材料关联。选用不会重算或修改毫米裁片，也不把材料名称自动转换成物理纹理或面料仿真。

## 二、真实协议与数据边界

后台通过完整服务地址 https://mcp.lasensys.com/mcp 调用 JSON-RPC tools/call，固定工具 basedata.material.list、版本1。只发送附件声明的查询字段，不调用中台内部Provider或其他工具。

已实际读取面料管理：最终浏览器回放包含启用列表第1/2页、编码FC-00315、精确ID查询。FC-00315返回“26S精梳全棉平纹”、100%Cotton，幅宽原值173、克重原值180。长ID1739493085997006850保留为精确文本；请求上游时按无精度损失的JSON整数发送。

实际返回为 result.content 中的JSON文本数组，没有总数，页面只显示“本页”条数，不推算全库统计。满页仅表示可以继续尝试下一页。空值保持“未提供”；零与false保留原意。幅宽和克重的输出Schema没有单位，页面保留原值；不能把计量单位KG/M解释为这两个字段的单位，也不推定采购价或库存价值的币种。

实际响应的长ID以字符串提供，兼容安全整数和精确整数字符串；不安全的数字ID停止处理。materialPic为真实响应附加字段，虽未列入提供的Schema，仅用于可选来源图片展示；其他未声明字段不自动用于业务。图片未提供时不制造示意图。

设计保存的是材料来源、工具版本、服务地址、读取时间和当时的数据快照，不能把旧快照的状态当作实时启用证明。款式中的材料摘要与资产关联导出均携带该快照。实际写回面料管理、修改审批、采购和库存均未开放。

## 三、连接配置

已有本机服务承担代理。服务优先读取进程环境变量MCP_ACCESS_TOKEN与可选MCP_ENDPOINT；也可在“面料管理 → 连接设置”中填写完整服务地址和访问凭证。更换服务地址时必须同时提供对应凭证，避免把原服务凭证带到其他地址。请求不跟随重定向。

当前凭证仅保留在本次服务进程内存中，不写入源码、Git、浏览器存储、设计记录、URL或业务证据。可清除连接；重启服务后需要重新连接，或由启动环境注入变量。前端只收到连接是否已配置及服务地址，不接收已配置的凭证。代理仅允许本机、同源工作台的操作，并限制为这一个只读工具。

运行方式保持原项目：npm run dev；也支持构建后npm run preview提供相同本机代理。纯静态托管不包含此代理。

## 四、验证

最终完整检查通过：64个测试文件、1266项测试，架构、代码检查和构建通过。面料管理7项、原工作台9项、矩阵15项浏览器步骤通过，共31项，0页面异常。其中1项权限失败使用明确的测试响应。构建仍有部分产物体积较大的提示。
