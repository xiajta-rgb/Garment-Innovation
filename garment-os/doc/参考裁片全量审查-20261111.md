# 参考裁片全量审查与显示修复

## 一、修复的具体问题

此前侧栏“衣领”等按钮只筛选当前款式。当前款式是T恤时，没有独立的梭织领面或领座，因此显示空画布；分类词典中的其他部位也没有跨模板图纸入口。

现在侧栏按部位打开独立参考库，真实显示对应源裁片。参考库、当前款式裁片、可执行制版生成器分别注明范围；查看参考不会更换款式或写入BOM。若要查看本款内容，点击“查看当前款式裁片”。当前款式确实没有该部位时，保留明确提示并提供参考库入口。

## 二、已沉淀资产与剩余缺口

| 范围 | 本轮结果 |
| --- | --- |
| 当前系统30种制版源裁片 | 全部有对应参考，不再只有定义或空入口 |

“全部大类有参考”不代表“129角色已全部建成”。64个角色还没有毫米CAD，其中61个连直接参考也尚缺；这些项在参考库的“本类角色覆盖与待补项”和[覆盖清单](evidence/reference-catalogue-20261111/coverage.json)中逐项列明，不能作全量验收完成。

衣领现有Simon、Carlton、Jaeger的领面、领底、领座与合并领面/领底参考；袖口包含罗纹、单翻和双翻，保留源直角、圆角、斜角构型。其余包括公主线身片、两片袖、帽中条、独立前门襟、袖衩、袋盖、嵌线、腰头、裤片、裙片、裆插片、挂面、胸衬、束身分片、帽顶、帽檐、护耳、领带、领结及披片。

手套类使用[开放授权实物纸样照片](https://commons.wikimedia.org/w/index.php?curid=140403603)，作者Kürschner / Kollektion Kuhn，CC0 1.0。图片显示掌背连体主片与拇指片；未提供可核验标尺，尺寸保持未知，不转换成毫米CAD。

## 三、图纸与工程规则

1. 每份CAD参考记录制版方法、固定版本、源裁片身份、路径键、构型设置、官方测量样本、源作者、源下料指令及净边周长。源几何保持不变，不用图标、AI描边或相似形状替代。
2. 原始净样、各段源缝份、布纹/对折、折线和可选细节分层显示。源未定义缝份时明确提示。Cathrin首部件中的两片轮廓分别保留，各自对应saA或saB，不混用另一片的缝份。
3. 参考库按大类、具体角色及关键词检索，12份一页；换分类、角色或分页立即选中对应图纸，不残留上一个衣领/袖口。可下载毫米SVG及源数据JSON。
4. 图纸使用来源的官方测试测量样本。它不是当前用户或工厂的实测尺码，参考库不自动向当前款式、BOM或三维装配注入裁片。
5. 几何仅在打开参考库时加载；新增上游方法属于开发依赖，不把全部制版引擎加载进日常画布。

## 四、实际验证与限制

完整检查：32个测试文件、782项通过；架构边界、旧归档完整性、代码检查与构建通过。

新增测试逐条独立重建34组FreeSewing构型，将172份样本的所有已展示路径和净边周长与上游一一对比，另核对所有源缝份段是否保留。22大类均运行显示与过滤组件测试，复现“T恤点击衣领”场景，验证参考库实际出现、源路径一致、原款式与测量数据不变。也验证缺图角色撤除旧预览，图片不获得虚构尺寸。

本机HTTP检查：页面、参考库模块及实物纸样图片均返回200。详见[全量检查日志](evidence/reference-catalogue-20261111/check.txt)、[HTTP记录](evidence/reference-catalogue-20261111/http-check.json)、[源提取清单](evidence/reference-catalogue-20261111/source-extraction.json)。

当前Work设置禁用浏览器操作，本轮没有真实界面截图，也未作界面验收。已准备 `npm run e2e:catalogue`，在允许操作浏览器的环境中逐类操作、核对172份实际DOM路径、输出各类页面截图和报告。该脚本本轮只作语法检查，未执行。

[衣领与袖口源图对照](evidence/reference-catalogue-20261111/collar-cuff-source-contact.png)和[全部源图总览](evidence/reference-catalogue-20261111/all-source-contact.png)由源SVG路径直接绘制，用于图形核对，不是浏览器截图。所有记录仍为生产未放行。

## 五、复建与维护

`npm run reference:build`依据固定依赖重新提取源图纸、生成轻量索引，并重建覆盖及缺口清单。新增裁片须精确登记源身份及角色，不按名称或形状猜测分类。手工修改快照会在独立源对照中暴露。

源码与[上游MIT许可](../public/reference-catalogue/FreeSewing-LICENSE.txt)随项目保存。研究资料位于 `research/reference-catalogue-20261111`；Valentina中的厨房手套文件实为几何缺陷重现样例，未将其方形测试轮廓当成真实手套。
