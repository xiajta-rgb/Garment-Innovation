# 品类持续接通与圆裙验收

本轮新增分幅圆裙的整款参考 CAD，采用锁定版本 `@freesewing/sandy@4.10.2`。服装构型总数仍为45；整款参考方法从7增至8，成衣曲面示意仍为5类，2类只有公司二维母版，35类尚未接通整款 CAD。分类定义、独立参考、可执行净样、成衣示意、浏览器验收和制造验收分别记录，不相互代替。

## 1. 圆裙的输入和裁法

入口：顶部“品类与功能”→裙装→分幅圆裙→选用此品类模板。可进入尺寸生成、配缝/BOM、构造参数与三维裁片检查；整件成衣三维入口保持未接通。资产库按该品类实际筛出三种结构：两幅半圆、两幅整圆和四幅抽褶圆裙。

| 输入 | 单位与语义 | 用途 |
| --- | --- | --- |
| 人体腰围 | mm，身体测量 | 自然腰位的腰头净长及裙腰半径 |
| 人体臀围、腰到臀深 | mm，身体测量 | 保留源方法的下身输入；当前自然腰位不等同穿脱开口已满足 |
| 腰到地长度 | mm，身体测量 | 源长度比例和腰头高度比例的基准 |
| 成品裙长 | mm，腰头顶至裙摆的独立设计长度 | 转为源 lengthBonus=裙长/腰到地；不是上装 HPS 衣长 |

参考样本默认取源人体腰到膝的值作为裙长设计初值，页面明确说明可修改。缺失值不从胸围或其他身体尺寸推断。保存、重新打开和撤销重做均保留裙长及构型选项。

仅开放自然腰位、直腰头、2–4幅、单轴对折的审查子集。圆度0.2–1、抽褶增加比例0–1、腰头高比例0.01–0.08、搭量比例0–0.15、下摆整理宽比例0.01–0.1。幅数必须为整数。范围内仍须通过完整几何约束，未审查的曲腰头、单幅整圆、双轴对折等不能输入或静默替代。

每个裙幅按源图单轴对折，数量是幅数；腰头是一片展开的连裁折腰，内侧由同片折返，不能再重复计入一片腰里。净样、源缝份、折线、布纹和裁剪指令完整保留。

## 2. 毫米约束与源算法边界

内腰弧半径为腰围×(1+抽褶增加比例)/(2π×圆度)。源裙身径向净长+源实际腰头成品高=输入成品裙长；腰头展开高=实际成品高×2，展开长=腰围+搭量，源折线位于半高。点位等式检查阈值为1e-6 mm，仅说明数值一致性，不是生产公差。

Sandy会将腰头请求高度吸附到常用规格。例如腰到地1050 mm、比例0.04，请求42 mm，源实际为40 mm，差值为−2 mm。构造报告分别显示三者，裙身按实际40 mm扣除，最小裙身净长限制也使用实际值；没有重新实现一套近似吸附算法。

圆弧由源三次贝塞尔曲线表达，不能当作解析圆精确相等。全部展开腰弧与解析值另按0.03%参考界限检查，和点位精度、配缝公差分开。腰头含搭量，裙腰可能含褶，不能把原始长边直接等长配缝。侧缝物理实例、开口位置/长度、扣合、腰头翻折、内侧固定及抽褶完成态均保持待验证，装配不放行。

## 3. 全库逐步验证方式

`scripts/audit-category-connections.mjs`从实际运行结果生成 `connection-stages.json`，按每个品类分别记录定义、参考CAD、裁片网格、成衣曲面示意、浏览器、远端同步和生产状态。未接通品类保留角色、尺寸、接口及缺口，不用参考图数量标记完成。

当前8个方法按男女两组参考体型、7个尺码重算，共112组，核对实际源身份、裁剪数量、边界分类、网格实例、源毫米往返和面积误差。5个支持成衣示意的方法在男女M样本各运行一次，共10组，检查曲面连接、非流形边与有效坐标。该检查没有人台碰撞和面料仿真，也不测量浏览器GPU帧率。

圆裙另有42组独立源对比：两组体型×7尺码×3种方案，直接与单独建立的原生Sandy制图逐片比对净样、控制点、源裁边和裁剪指令。六个可编辑参数各检查最小/最大边界，另查三幅构型、缺失/非数值输入和不兼容选项。组件交互检查覆盖品类选用、五项输入、调整裙长、裁剪片数、非法小数、腰头吸附差、结构筛选、模板缩略图和三维入口；绘图设备在组件测试中被替换，不能冒充真实浏览器验收。

```powershell
npm run check
$env:GARMENT_EVIDENCE_DIR='doc/evidence/category-connection-20261111'
node scripts/audit-category-coverage.mjs
node scripts/audit-category-connections.mjs
node scripts/render-asset-library.mjs
node scripts/verify-svg-projection.mjs doc/evidence/category-connection-20261111/svg-projection
$env:GARMENT_MESH_INPUT_DIR=$env:GARMENT_EVIDENCE_DIR
npm run verify:mesh-worker
node scripts/verify-category-connection-evidence.mjs
```

证据保存在 [本轮目录](evidence/category-connection-20261111/)。`check.log`保留完整检查结果，`verification.json`汇总通过项和文件校验，`native-worker.json`验证当前正式构建引用的后台模块，`connection-stages.json`逐项列出45类状态。图片为真实源SVG离线渲染并经查看，不是页面截图。历史工作台报告保留原阶段数字。

## 4. 未接通方法与协同资料

Penelope直裙暂不启用。已安装4.10.2版的 `src/waistband.mjs`中，说明长度使用腰围×搭量比例，而实际展开点位将比例直接加到半腰围；前片和腰头还存在对折图示与裁剪清单声明不一致的问题。未经独立修复和源裁法核实，不能猜测更正。原始源哈希、点位、裁边及裁剪指令保存在 `research/category-connection-20261111/penelope-probe.json`；Sandy原始探针在同目录。

待登记候选现包含Aaron、Huey、Sandy三个方法及13种源裁片，新增裙装字段定义、比例语义、源身份、角色、材料和数量。候选无远端记录ID，未写入飞书，不改变现有表的发布状态。后续继续优先完善同源完整构型和完成态接口，不能通过把不兼容的现有模板改名来覆盖剩余品类。

本轮验收范围为系统逻辑、源图纸与离线映射；真实页面交互和截图按用户安排暂缓，制造批准保持未通过。
