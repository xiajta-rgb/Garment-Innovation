# 资产与模板库联动

本轮新增主工作区“资产与模板库”，公司设计稿内也可通过“从资产库选用面料 / 工艺”进入。沿用当前公司参考母版及源毫米制图方法，资产选择、撤销、保存、重新打开和候选导出共用同一份款式状态。

## 一、已沉淀的内容

| 库 | 本轮内容 | 选用后的实际作用 |
| --- | --- | --- |
| 面料库 | FC304、FC-00332、310g卫衣布、420g的2×2罗纹，共4种原稿材料 | 分别关联衣身、领口、袖口、下摆；主料更新图稿的面料、成分与克重文字，配料独立保存 |
| 工艺方案 | 短T与长T的2套参考方案 | 罗纹领高、下摆/袖口折深、双针间距进入同一份二维/三维工艺设定 |
| 结构组合 | 衬衫6种、开襟帽衫4种、背心3种，共13种 | 先按当前体型生成真实源裁片预览，再显式应用至裁片、装配关系与源裁剪BOM |
| 公司母版 | 汇集既有4份真实公司原稿 | 选择后回到公司设计稿；只有已接通的短T/长T允许关联参考CAD |
| 裁片模板 | 汇集现有12项模板及各自建设状态 | 7项有完整参考制图方法；4项待重建、1项停用，入口继续禁用 |
| 配色库 | 既有30种屏幕色增加稳定ID和版本引用 | 更新公司设计稿；在该母版已显式关联CAD时同步其外观颜色 |

13种结构组合是现有完整制图方法的参数方案，不是新增13种独立制版方法。衬衫支持三种单翻袖口、三种下摆及短袖折边；帽衫支持罗纹与前袋开关；背心支持领深、肩带及包条联动。Huey始终是开襟帽衫，不能作为公司套头帽衫的替代。

## 二、参数与引用规则

1. 每个资产使用稳定ID与修订。材料、配色、工艺引用随公司草稿保存在现有设计文件中；未选资产的历史文件继续兼容。
2. 衣身与各部位配料独立。2×2罗纹的成分未知，不能继承衣身66%涤纶/34%棉。帽衫无独立罗纹领，不能向其领口位分配罗纹领材料。
3. 原稿的180g、310g、420g按原文保留；单位面积克重、门幅、伸长、缩水保持空值。屏幕色不等于实物色卡。
4. 手工修改面料、成分或克重，自动解除与原主料的关联；独立配料仍保留。修改颜色或工艺参数，也只解除对应的过期方案引用。保存文件中的伪造ID、版本、角色和不一致字段会被拒绝。
5. 结构预览不改变当前款式。应用时整体替换该方案的参数，清掉长短袖、袋形、罗纹等不适用的旧参数，并执行现有完整制图与配缝检查。
6. 衬衫方案明确包含Simon默认25%衣长加长：`衣长=(HPS至后腰+腰臀长)×1.25`。界面展示当前衣长、方案衣长及更新说明；这是可编辑设计输入，不是从原稿推断的尺寸。

## 三、此次对照发现并修复的问题

原默认参考体型的衣长恰好到臀围线，此时圆弧摆/开衩摆会退化为相同形状。新衬衫方案使用明确的源参考衣长；手工选到退化情形时，工艺报告会提示缺少臀线以下延伸。

在真实非零衣长下，旧装配合同仍固定使用`hem`构造点，但该点已不在曲线下摆的净样轮廓中，导致无法分类边界。现按源方法分支定位：平摆使用`hem`，圆弧摆使用`bballEnd`，开衩摆侧缝从`hips`开始。开口边保持自由收边，不能误缝为侧缝。衬衫装配修订升级为`assembly-v2-curved-hem`，没有修改上游曲线，也没有放大走缝公差。

预览改为逐片显示，保留原始曲线、布纹、折线和裁剪数量；线宽只作屏幕适配。显示的毫米外廓包括源缝份和制图标记，不代表成衣尺寸，各预览小窗也不代表彼此同一显示比例。

## 四、验证与验收范例

自动检查覆盖：13种结构×2种体型×3个尺码的78组生成；三种衬衫下摆×三种非零衣长延伸×两种体型×三个尺码的54组配缝检查；另直接与Simon源输出比较前后3片的原始净边，确认三种下摆确有不同曲线。还覆盖筛选实际显示、阻止不兼容选用、预览与应用路径一致、保存重开、撤销重做及过期引用解除。

可重放范例：

1. 进入资产库，以长T为目标，主料选FC304、领口配料选FC-00332、配色选中灰、工艺选LT26M1581。返回公司稿后核对文字和颜色，保存、新建、重新打开后核对资产引用。
2. 结构组合筛选衬衫，依次预览三种袖口及下摆，核对逐片毫米外廓和实际曲线。短袖方案只能出现7种裁片，不应残留袖口和两种袖衩。
3. 开襟帽衫切换罗纹/袋开关，裁片种类应为7、6、5或4。背心改变领深，领窝与领口包条同时重算。

实际离线渲染和记录位于`doc/evidence/asset-library-20261111/`：`structure-overview.png`、13份独立裁片图与整幅SVG、`linked-company-long-tee.png`、`linked-assets-example.json`、`offline-validation.json`。这些是源SVG离线渲染，**不是浏览器截图**。

浏览器验收遵照用户安排继续留待稍后。`scripts/e2e-asset-library.mjs`已预留真实操作、保存重开、筛选与逐步截图流程，尚未执行；须显式启用才会启动浏览器。测试和离线图不能作为浏览器或制造验收通过的证据。

## 五、后续协同边界

“导出资产关联候选”包含原稿来源、资产修订、独立用料部位、当前参考裁剪数量、已有元素库快照匹配记录与快照日期。未知采购数量继续为空。公司稿未显式关联当前裁片时，导出明确标记未关联，不可当作同款BOM。

本轮没有修改飞书。导出使用现有元素库快照坐标，既有记录只能作为快照线索，不能当作实时确认。圆领罗纹卫衣与套头帽衫的独立CAD/完成态三维、完整领底、袖口翻折、实际排料与物性测试继续列为缺口。全部保持`productionApproved=false`。
