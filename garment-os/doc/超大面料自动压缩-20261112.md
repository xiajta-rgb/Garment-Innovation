# 超大面料自动压缩套用

在资产库选择“套用来源图片与资料”后，超过12MB的面料图自动压缩，再进入现有三视图套料流程。无需用户另存或手动处理。保留原始面料编码、来源地址和原图查看，不修改企业面料记录。

压缩时保持比例，不裁剪、不放大小图；处理EXIF方向，输出最长边不超过2560像素的WebP，优先使用90质量，必要时继续降低尺寸和质量，使传输图不超过4MB。设计方案继续使用原有最长边768像素的嵌入图。普通面料图沿用原流程。来源读取有64MB与压缩解码8000万像素的处理边界，损坏图片或处理失败会明确提示。

## 实测

真实企业面料FC-00315，来源原图7008×4672：

| 阶段 | 大小 |
| --- | --- |
| 原图 | 22,399,729字节，约22.4MB |
| 自动压缩传输图 | 988,152字节，约0.99MB |
| 方案嵌入图 | 768×512，36,205字节 |

在插肩T恤加单胸贴袋的三视图上完成套用，并验证撤销、重做、保存后的图片与来源资料，以及套料后仍可查看原始高清图。浏览器6项检查通过，无页面运行错误，截图已人工检查。未发起森灵生图。

专项测试25项通过，涵盖真实超大图片压缩、比例及颜色、无长度声明的下载、超出读取边界时中止、损坏图片失败提示，以及面料应用目标。架构检查、代码规范、类型检查和生产构建通过；本次未重复运行全部测试。
