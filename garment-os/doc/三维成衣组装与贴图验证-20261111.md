# 三维成衣组装与贴图验证

2026-11-11。默认入口已从散开裁片改为“**三维成衣**”；“裁片检查”作为独立工作方式保留。

**更新说明：**本文记录首轮组装实现。源弧长站位、显示细分、布厚/侧壁、最新形变和测试结果已在[三维成衣表面与边缘对照](三维成衣表面与边缘对照-20261111.md)更新。下文的916项测试、0.8mm近点合并和首轮形变数值均属历史记录，不能作为当前结果。

## 1. 本次实现

源 CAD 净样 → 对折展开 → 有内部顶点的约束三角网格 → 逐边配缝与袖片闭合 → 曲面约束松弛 → UV与材质 → 显示/导出。

没有另画一个通用衣服模型来替代实际裁片。CDT网格边界来自已有毫米净样，内点仍在同一二维域，三维曲面与原始裁片分开保存。每个表面保留源裁片身份、物理副本、展开毫米、折边反映射、共享连接点和三角面索引。原始CAD、数量及BOM依据不随渲染改变。

配缝按已有结构定义的边界和方向串联，不通过“看起来相近”猜测。两侧加入共同站位后连接到同一顶点位置。袖山对应前袖窿与反向后袖窿的连续链。拓扑检查要求一个连接体、没有三面及以上共边，保留四个开口；不通过则阻断显示。

预览复核发现短袖初始圆筒穿入衣身、袖山内折，已改为从源袖窿链向袖口环延伸的初始曲面，再执行约束松弛。形变统计也改为逐片独立计算所有三角网格边，包含配缝两侧各自的源长度；不会因求解器共边去重而漏计另一片形变。

## 2. 贴图及导出

- 面料：纯色、条纹、格纹、斜纹、UV检查格。循环尺寸使用源裁片毫米坐标，旋转相机不改变UV或纹理周期。
- 本地图片：PNG/JPEG/WebP，最大10MB、边长4096px；可选择满幅循环、单幅铺满裁片、仅前衣身或所有已组装片，以及90°方向切换。当前是整片表面贴图，尚不是可自由拖动的局部印花贴花工具。
- glTF：嵌入图片，包含POSITION（米）、NORMAL、TEXCOORD_0、展开_CAD2D与原始_SOURCE2D（毫米），并附配缝、形变及未装配清单。可由独立glTF读取器重读。
- 图案在本机当前会话预览，导出文件携带图片；本轮没有扩展设计文档的贴图持久化，也没有自动登记飞书资产。

主显示使用Three.js实体材质、曲面法线与棚灯。兼容显示使用同一曲面的三角形与UV仿射变换，支持真实位图映射。两者共用相机坐标和毫米来源；兼容模式不承诺大网格帧率。旋转不重传顶点、不重算裁片，不对大图逐帧序列化，不反复重设画布尺寸。静止时不持续绘制。

## 3. 已验证与未验收

全量检查37个文件、916项通过；另做成衣材质适配与界面专项。架构无环路/越界依赖，类型与正式构建通过。

- 5类模板 × 男女参考样本 × S/XL，共20组：检查源数据不变、数量、毫米UV、共享连接点、独立共边计数、四个开口及面积。
- 独立三角形反向拾取、UV毫米周期、图像旋转和仿射贴图的数值对照通过。
- 独立glTF读取器重读曲面、单位、UV、源坐标、前片材质分配和两份嵌入贴图通过。
- 组件交互检查覆盖默认成衣入口、换色/图案、尺寸、上传/移除、前片贴图、导出、过时后台回复、任务取消及未支持款式。GPU与文件读取受测试替身控制，不作为浏览器验收。
- 当前构建实际引用的成衣Worker在无页面的原生子线程运行：Brian、Teagan、Aaron生成成功，未接通的Huey明确拒绝。另重验7模板原裁片Worker。
- 同一React兼容组件离线输出5款×3视角，共15份含位图UV的投影图，并已查看联系图。**这些不是浏览器截图。**

当前只是几何约束组装预览。默认男装M码样本的边长形变P95约为：Brian 4.78%、Teagan 7.13%、收腰Teagan 7.00%、Sven 4.28%、Aaron 2.20%。局部最大形变仍明显偏高（Brian约70.3%、Teagan约77.1%、收腰Teagan约76.8%、Sven约76.0%、Aaron约15.0%），不能据此判定合体、面料可实现或生产精度。界面始终显示实际指标和“形变待验收”。边界网格合并站位最大偏移约0.8mm，源CAD并未按此精度改写。

缺少材料标定、完整人体碰撞、自碰撞、重力垂坠、缝份/厚度/翻折与附件完成态；`drapeValidated`、`productionApproved`保持false。后续需降低局部形变并建立材料与碰撞约束，不能用漂亮贴图代替这些条件。

真实浏览器操作和截图仍按用户先前安排延期。`npm run e2e:garment`已准备6步实际操作流程，覆盖旋转截图、材质替换、本地图片、前后面、兼容显示及返回源检查；本轮只验证语法，未执行。硬件GPU帧率也尚未实测。

## 4. 复核与依赖

```powershell
npm run check
npm run verify:garment-worker
node scripts/render-garment-offline.mjs
# 浏览器允许使用后再执行：
npm run e2e:garment
```

证据位于`doc/evidence/garment-assembly-20261111/`：`check.log`、`source-matrix.json`、`native-worker.json`、`offline-verification.json`、`garment-preview.png`及`brian-textured-garment.gltf`。

采用[cdt2d 1.0.0](https://github.com/mikolalysenko/cdt2d)的约束Delaunay三角化（MIT），遵守其无重复点、无交叉边、无T接头前提；过滤过近边界点并检查面积和拓扑。约束松弛参考[PositionBasedDynamics](https://github.com/InteractiveComputerGraphics/PositionBasedDynamics)介绍的PBD方法，仅借鉴距离约束思想，没有宣称接入其完整求解器。保留原FreeSewing 4.10.2毫米制版链和Three.js 0.187.0渲染链。
