# 标签组合与素材配套审查

本次在原设计台补充了开襟与工艺控制、标签组合输入、素材匹配、组合缺项与公司原稿对照。输入标签词或稳定编码后，检查通过即可更新当前短T设计三视图；保存、撤销、原有口袋和面料联动继续沿用工作台。

## 核查结论

现场读取标准叶子标签镜像439项（修订2629），元素素材库78项与制版参数61项。没有素材同时满足“可用、标签已核验、正式标签编码、字典版本”；5项存在候选关联。现有候选不能视为正式标签到可用裁片的映射。素材库来源和标签字典来源已留证，未回写企业表。

这轮打通了标签到二维设计表达的局部链路，没有打通趋势检测到生产裁片的全自动链路。图稿的裁片划分是设计表达；领襟、插肩、全开襟等尚不能复用基础圆领净样作为同款完整纸样。源净样仍可参考查看，新增工艺不改变它的制版资格。原有设计矩阵的结构审核状态保持有效。

## 已补入原设计台

- 领部：圆领、V领、亨利领、Polo翻领、立领。
- 门襟：纽扣短门襟、半开襟拉链、全开襟拉链设计表达；开口长度与宽度可调整。
- 工艺：领口窄包边、后领内侧包条、肩袖压线、嵌条；包边宽度、领高和配料颜色可调整。
- 标签组合：现有词或编码匹配、互斥与缺项检查、部位确认、应用、稳定编码与部位随方案保存、当前组合的缺片清单及全量待完善清单导出。
- 包边与包缝保持独立；未指定门襟范围的拉链不直接应用，拉链口袋、连帽和大落肩等缺配套时停止自动应用。嵌条未找到对应标准词，不借用包边编码。材料组织与肌理外观分开，标签预设不证明真实组织。

入口：设计台 → 裁片组合设计 → 开襟 / 工艺、标签组合。

## 自动推进所需的配套资料

每个生成规则至少需要：正式标签编码与字典修订、产品核/材料类型、部位与层位、模板版本、配套素材ID、输入参数及来源、净样/缝份/布纹/裁剪份数、装接边/剪口/缝止点、分段缝长与允许吃势、完成态折返与包覆、前后侧绘图位置、辅料规格、适配约束和审核状态。一个标签可能需要一组裁片、辅料与工序，不能一词只找一片。

先补：亨利左右门襟与补强、Polo领片与短门襟、立领与短拉链贴边/底挡、包边截面与长度、插肩前后身袖配缝。随后补：全开襟左右前片、三片帽、拉链袋、罗纹收口、开衩及图案工艺。

趋势侧后续传入的最小组合应包含：标签稳定编码、产品核、明确部位、期望值、尺寸/基准、材料ID以及字典修订。趋势证据与“设计组合可生成”是两件事；本次未接市场趋势判定。缺素材、版本不同、参数不足或组合冲突时返回缺项，不退化为近似替换。
