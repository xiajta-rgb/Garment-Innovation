# 裁片组合设计与森灵立体、模特图实测

本轮按“先做T恤，跑通专业改款链路”实现。入口为顶部“裁片组合设计”，也可直接打开 <http://localhost:5341/?workspace=piece-design>。

## 一、设计链路

1. 用当前尺寸创建直身或收腰T恤。前后衣身及配套袖片来自 FreeSewing Teagan 4.10.2；圆领、短袖延伸、袖口宽、衣身松量与设计衣长均通过源方法重算，不用屏幕缩放代替制版。
2. 组合对折罗纹领条与独立贴袋。领条依源领窝净弧长计算；贴袋可选方底、尖底、圆角或无袋，独立设定毫米宽高与袋位，可在前衣身展开图拖动定位。
3. 检查净样、裁边、裁剪数量和配缝。三视图读取这组裁片的配缝关系及装接结果，正背侧使用同一比例，逐片配色与袋位同步。
4. 向森灵提交当前三视图图片，选择“立体产品图”或“模特穿着图”。提交时冻结方案；继续编辑不会修改已提交参考。

默认带袋方案为5种裁片、共6片：前衣身1片对折裁、后衣身1片对折裁、袖片2片、领条1片、贴袋1片。去掉贴袋后相应减为4种、5片。这些数量属于参考方案，未包含面料损耗或采购用量。

## 二、尺寸与配套

| 部件 | 尺寸依据与检查 |
| --- | --- |
| 衣身、袖片 | 同一个源方法和同一组尺寸；改袖、改领后重新核对肩缝、侧缝、袖底及袖山；界面显示两侧净长、差值和源方法的判断。 |
| 领条 | 净长=前后领窝净弧长×设计比例；裁长=净长+两端各6mm；展开宽=2×(成品高+6mm)。保留折线与四等分标记。默认比例0.9属设计设定，不能当作实测回弹。 |
| 贴袋 | 净样宽高为明确毫米输入；默认侧底缝份6mm、袋口折边20mm；袋位相对前中与源肩颈最高点。裁边距衣身边界至少10mm。只装接侧底，袋口保持开口。 |
| 三视图 | 从同组裁片的配缝示意生成，保留源毫米坐标与三视图的示意坐标区别；正背侧同一比例。不是布料垂坠模拟。 |

原公司稿外观选项仍在“公司设计稿”，其任意V领、Polo、帽衫外观不会被当作已接通的裁片组合。当前专业组合入口只支持已配套的两种Teagan T恤及本轮领条、贴袋规则；没有开放任意跨款裁片拼接、分割重构、任意曲线编辑、放码或工业DXF交换。

## 三、保存与导出

顶部保存、撤销、重做及保存重开包含组合设定。切到不兼容方法时解除组合设定，避免把T恤贴袋/领条规则套到其他整款。

可导出三视图SVG、参考PNG、毫米裁片SVG、设计与配缝JSON。毫米SVG保留源净样与裁边坐标，只有版面平移，文件物理单位为mm；JSON含源方法、尺寸输入、裁法与配缝。领条和贴袋仍为待复核的尺寸化草案；SVG不等同于工厂已批准的净样。

空白、越界尺寸或不合适袋位会停止组合预览、导出与出图，不能默补为0。未修改的输入失焦不会新增撤销记录。测试请求先保存提交意图，再执行出图；生成中或结果不明确时仅允许查询原任务。浏览器标签内刷新可恢复测试记录；仍应下载备份，本地查询索引30分钟后或服务重启后失效。

## 四、实际森灵出图

通过真实编辑器，以同一个“深绿衣身、米色袖与领条、左胸米色尖底袋、延伸短袖”组合，串行提交两次，均成功返回。两次提交参考PNG的SHA256完全一致，且分别与服务返回的inputSha256一致。

| 输出 | 实际目视检查 | 限制 |
| --- | --- | --- |
| 立体产品图 | 有服装体积、织物质感与自然明暗；深绿衣身、米色短袖与罗纹领、左胸尖底袋均保留。 | 领深、廓形和褶皱由模型重新解释；领内增加小型空白标签。不是可旋转三维模型，也不能据此量出115×135mm袋片尺寸。 |
| 男模穿着图 | 成年男模展示整件衣身与下摆；主要配色、圆领、短袖及左胸尖底袋保留，双手和衣身可见。 | 姿势接近正面、带轻微侧转；合体、袋位毫米误差及背部不能由这张图验收。 |

棉感平纹针织是此次效果设定，未取得材料成分、克重及物性测试，图片不构成材料事实。两张输出可供设计评审，人工验收与生产批准仍待完成。

原图、冻结参考、当时组合与任务记录见[实际对比页](evidence/piece-design-20261111/comparison.html)。页面截图来自本地编辑器，使用森灵AIS接口实际生成，不是森灵自由画板截图。此前Polo/帽衫二维外观测试单独保留，不混作本轮裁片链路证据。

## 五、检查证据

实际出图证据为senling-live.json，刷新恢复两条测试且未新增提交的证据为senling-session-restore.json；汇总及文件哈希核验见verification.json。完整测试与页面检查不代替实物试样和生产放行。
