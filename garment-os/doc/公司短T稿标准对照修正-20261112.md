# 公司短T稿标准对照修正

本轮基准为真实公司原稿 COT25M002（研发货盘记录 reczz28Xjq3qifFs），不是上一轮净样展开图。

## 对照后的修正

1. 主图改用公司款式图的比例与线稿方式。保留圆顺肩线、自然向下的袖势、收敛的腋下转折和较修长的衣身；不把纸样展开的袖窿直接画成上身轮廓。
2. 前视保留后领圈层次，前后领深分别表达；袖口及下摆补双压线。主图使用连续矢量线，避免细小网格碎线。
3. 原组装侧视的椭圆袖洞退出主图。公司没有侧面原稿，补充侧视明确标为设计补充，无实测厚度或垂坠结论。
4. 原工作台和矩阵共用新画法。工作台可点击“对照公司原稿”，直接展开原始设计稿。裁片尺寸表与展开量点图折叠保留，明确其来源是Teagan参考裁片。
5. 新建方案默认同色无袋，避免把配色演示当基础款。现有方案及贴袋参数不覆盖；同配置重画保留全部源裁片路径。
6. 衣长、胸宽、肩宽、袖窿深、领宽领深、袖长和袖口调整以当前参考裁片相对于同尺码中性配置的变化传递给款式图。绘图坐标使用公司稿比例，不能标称同款毫米成品尺寸。矩阵整组统一绘图尺度。

## 必须明确的差别

公司COT25M002标注微落肩；当前已接通的Teagan是装袖。新版参照公司稿的绘图标准，内部袖缝按装袖派生表达。它不是已经审查通过的公司同款纸样。源微落肩关联保持为空，插肩、落肩和其他未配套结构不自动放行。

原稿写明尺码尚未确认；目前没有公司同款毫米净样，不能靠图像比例生成生产尺寸。后领包边、双针间距、缩水率、回弹和试衣仍需独立确认。画面上自然的袖姿也不构成布料仿真证明。
