# 短T轮廓与边界线完善

沿用公司 COT25M002 指导下已认可的款式比例，优化款式图的边界和工艺线。公司原稿、参考毫米裁片、配色、袋位和量点输入均保留。

## 本轮调整

- 正背面外轮廓单独连续绘制，外边界、装袖缝和双压线分三级线宽，去除共享边的重复描线。
- 下摆保留原有浅弧，两端接侧缝采用小圆顺转折，双压线复用同一弧度并与侧缝求交收口。
- 袖上线延续肩部切线，袖口小转角与腋下共用圆顺曲线；袖口双压线按袖口法线偏移后与袖边求交，保持平行。
- 同色衣身和袖片增加无裁片身份的轮廓底色，消除相邻填色抗锯齿产生的浅色裂缝。结构线模式同时清除该底色。
- 压线颜色随对应布片颜色调整，深色款能看清工艺线；侧面同步调整下摆和双压线。
- 原工作台、定制矩阵和导出共用相同绘制逻辑。
