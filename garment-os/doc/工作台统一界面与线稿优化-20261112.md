# 工作台统一界面与线稿优化

## 一、入口与排版

原工作台保留顶部保存、导出、撤销与左侧模板、尺寸，共用当前款式。主导航收敛为四个入口：

| 入口 | 内容 |
| --- | --- |
| 设计台 | 裁片组合设计、定制矩阵、三维映射、款式工作流 |
| 资产库 | 面料、工艺、结构组合、裁片模板、配色 |
| 裁片库 | 当前源裁片、参数生成、检验、配缝组成、部件构型、分类 |
| 参考资料 | 公司设计稿、跨模板参考裁片、品类与功能、模板审查、基础裁片核对 |

公司母版浏览从资产分类移出，归入参考资料；资产的应用目标折叠在“应用范围”，保留母版关联和返回参考资料的入口。参考浏览本身不改当前裁片或测量。

统一模块标题、卡片、按钮、筛选状态、间距和深浅主题。裁片分类使用统一强调色，检查通过/失败保留状态色。三维工具栏、属性栏跟随工作台主题，绘图纸面保留浅色。矩阵加载占位与图稿采用相同画幅，减少加载前后跳位。

手机端保留四个主入口，“模板与尺寸”打开同一侧栏。生成器参数区与预览上下排列；检验页的筛选清单、完整裁片预览、检查项分区显示，避免固定侧栏把图纸挤成窄条。实际检查预览宽度与滚动，并非只检查页面无溢出。

## 二、三视图线条

原图从组装曲面投影后，像素轮廓和局部网格弯折造成侧边小波折、直边贴袋变形以及短线迹碎点。

1. 显示轮廓先消除像素阶梯，再做有限简化和浅转角圆顺。袖角、腋下等明显转角保留；小轮廓使用更小的简化界限，孔洞分别保留。
2. 正面贴袋从原毫米CAD的角点投影，恢复尖底袋的五条直边；不沿局部网格弯曲重复描边。
3. 合并极近的可见线迹段，过滤不足以辨读的碎段，降低密集领条纹线干扰。配色轮廓下增加同色底层，减少独立轮廓之间的白缝。
4. 原始毫米裁片、尺寸和配缝输入未因显示清理而改变。图稿仍为组装参考示意，生产未验收。

保留同一测试款、同一配置和同一视角的优化前后SVG、PNG与并排对比。这个测试样本的指定侧边区域，轮廓方向反转由10次降至2次；尖底贴袋投影为五条直边。该指标仅说明此样本的边缘稳定性，不代表全库制造精度或全部款式验收。
