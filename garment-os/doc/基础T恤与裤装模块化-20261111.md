# 基础 T 恤与裤装：基型、变化与部件接口

优先沉淀可反复改款的基础衣身和基础裤片。本轮固定 FreeSewing 4.10.2 的 Teagan 与 Paco 为可重放的源制图依据；源方法一致性用于系统验证，不等于工厂制版认证。

## 可使用的基础能力

| 基础款 | 已接通变化 | 实际裁片与限制 |
| --- | --- | --- |
| 圆领 T 恤、收腰针织上衣 | 基础短袖、加长短袖、收口短袖；领宽与前领深 | 前后身各对折裁 1，袖片裁 2；独立领条净样待接通 |
| 松紧腰基础长裤 | 基础直筒、加宽脚口、缩短裤腿；臀部松量与腰头高度 | 前后裤片各裁 2、腰头裁 1，共 5 片；当前无袋、无束脚接条 |

入口为顶部“品类与功能”，选择“圆领短袖T恤”或“松紧腰基础长裤”，明确“选用此品类模板”，再选“基础款快速改款”。也可在“资产与模板库 → 结构组合”按品类筛选、预览并应用。预览不直接修改设计；应用后尺寸、裁片与配缝/BOM 候选一起更新，支持撤销、保存和重新打开。

T 恤袖长控制的是**上臂线以下的延伸量**，不是直接输入肩点到袖口的成品袖长。源袖下口宽存在上限，报告分别列出请求值、实际值和限制差。改变短袖延伸与袖口宽时，袖山及前后衣身保持同源。插肩、落肩、泡泡袖等需要配套重制衣身接口，当前未开放。

裤装独立输入腰围、后腰弧、臀峰围、后臀弧、前后总裆弧、前裆弧、腰到高臀/臀峰/大腿根/膝/地、膝围及脚跟通过围，共 13 项。前后弧是直接测量，不能取半围；纵向站位须依次成立。源腰头按常用松紧规格吸附高度，报告分别显示请求与实际值；腰头一片折返，不能重复记腰里。裤腰展开长由前后腰口净长决定，松紧带成品长度仍为待测值。

## 后续加袋、换袖的统一接口

每个部件保存稳定身份、修订、适用基型、宿主/部件角色、关键尺寸、安装边和定位要求、源身份、参数及阻断原因。此次定义 5 项：装袖短袖、圆领变化、胸贴袋、裤腿/脚口、裤侧插袋。

胸贴袋须有袋净宽高、袋口折深、缝份、左右和数量，以及相对前中线/HPS 的位置；安装轮廓须落在完整前身净样内，并避开领口、袖窿和折边。**本轮只完成接口定义，尚未生成可装配袋片。**

Paco 前袋源文件实际使用 `paths.pocket`；袋布存在对折图示/轴 `cutOnFold`，材料清单却为 `onFold:false`。原始输出和文件校验保存在 `research/foundation-blocks-20261111/native-contracts.json`。当前严格拒绝开启该源前袋、后袋或束脚开关，防止只改变衣身却漏掉配套片。后续须核清裁法，再接入全套净样、定位、配缝、材料层及数量。

裤片内外侧缝和裆缝已有专用语义、站位顺序及走缝检查；0.1mm 是源曲线数值检查限值，**不是制造公差**。腰口总长虽已核对，左右裁片实例顺序、腰头接头、折返及松紧完成态仍待定义，所以不放行整件装配。

## 本轮验证与界限

- 54 个测试文件、1194 项测试通过；架构、代码检查、类型检查、正式构建通过。包括真实改款入口、无效输入撤图/保留、恢复构型、筛选、撤销与保存恢复；额外核对袖口宽度上限，收口方案必须实际变窄。
- 42 组裤装独立源对比：男女样本 × XS–XXXL × 3 个方案，逐一核对净样、源裁边、坐标、裁剪清单和 5 片毫米网格。
- 18 组 T 恤袖片对比：男女样本 × S/M/XL × 3 个方案，确认与原生 Teagan 完全一致，衣身与袖山不变。
- 全库 126 组源裁片/三维刚性映射检查；25 个结构方案的实际裁片离线图；27 份真实兼容显示组件的离线 SVG。图纸逐片适配视窗，并非相同比例排料。
- 当前正式后台模块在原生线程执行 30 个场景：18 个默认样本、6 个基础改款、6 个错误输入。显示缓冲转移后原毫米数据保留。

所有证据位于 `doc/evidence/foundation-blocks-20261111/`，总清单为 `verification.json`。最终校验脚本会核对测试结果、源文件和产物校验值，避免沿用旧通过记录。

浏览器页面操作与截图依用户安排暂缓。裤装仅支持源裁片三维检查，尚无整件裤装三维；T 恤三维仍是示意，无面料物理仿真。未获得生产批准。本轮仅导出本地元素登记候选（含部件接口），没有写入飞书。

## 可重放流程

在 `garment-os` 目录运行，保持旧证据目录不变：

```powershell
npm run check *> doc/evidence/foundation-blocks-20261111/check.log
node scripts/probe-foundation-sources.mjs
$env:GARMENT_EVIDENCE_DIR='doc/evidence/foundation-blocks-20261111'
node scripts/audit-category-coverage.mjs
node scripts/audit-category-connections.mjs
node scripts/render-asset-library.mjs
node scripts/verify-svg-projection.mjs doc/evidence/foundation-blocks-20261111/svg-projection
$env:GARMENT_MESH_INPUT_DIR=$env:GARMENT_EVIDENCE_DIR
npm run verify:mesh-worker
# 本地服务启动后检查当前页面与关键模块是否可访问，再汇总证据。
node scripts/check-foundation-http.mjs
node scripts/verify-foundation-evidence.mjs
```
