# 工作台矩阵模块整合

后续导航与排版已统一，当前界面以[工作台统一界面与线稿优化](工作台统一界面与线稿优化-20261112.md)为准。本报告保留矩阵整合与交互验证的记录。

独立设计台已整合进原 GarmentOS 工作台，移除独立品牌栏和重复模板库。首页 `/` 保留原裁片组合设计与当前默认模板；选择左侧基础短T，再点击原工具栏的“定制矩阵”。所有旧矩阵链接仍可打开，统一使用原工作台外壳。

## 一、统一交互

1. 原左侧模板库、人体尺寸、尺码和配色是唯一当前款式入口。矩阵读取完整当前基版，包括手动尺寸、既有领口、领条、口袋和工艺设置。切换其他模板会显示该模板的源裁片，不套用短T设计。
2. 右侧多选定制项，中间自动展开全部组合并分页；先比较方案，再点击“应用到当前款式”。探索候选不会自动替换当前款式。应用进入原撤销/重做历史，可切回裁片组合、三维映射继续检查。
3. 顶部 Save 保存已应用的当前款式；顶部 Export 在矩阵模块导出当前候选三视图，有结构缺口时导出设计需求。选款夹保存完整基版快照，“继续定制”恢复当时尺寸与选择。旧存储保留。
4. 模板审查、基础裁片核对在工作台中切换，并有返回矩阵按钮。原模板库和顶部操作持续可用。模块采用原工作台主题与强调色。
5. 手机使用“模板与尺寸”打开同一侧栏，专用关闭按钮收起；顶部保存/导出保持可见，矩阵可横向滚动。清空测量值时保留编辑界面、暂停预览并提示修正，补齐后自动恢复。

## 二、结构范围

只为有配套依据的圆领、标准装袖、平纹男士短T计算裁片参考。V领、亨利领、插肩、落肩及未接组织保留需求和具体缺口，禁止应用为现成结构。所有模板仍为生产未验收；此次整合不改变审查结论，也未提交森灵生成任务。

## 三、验证与证据

完整检查通过：63个测试文件、1256项测试，架构检查、代码检查与构建通过。真实Edge浏览器15项整合流程、20项模板审查和7项基础裁片回归通过；均为0页面异常、0生成提交。核验包括实际手动尺寸、换色与换码、清空恢复、方案应用及撤销/重做、保存重开、原顶部导出、模块切换、主题跟随、手机侧栏与矩阵滚动，以及旧链接和旧存储保留。

最终结果记录在 [verification.json](evidence/workbench-matrix-integration-20261112/verification.json)，含完整检查日志、真实浏览器操作、桌面/手机截图、实际SVG与JSON下载、保存后数据库读取记录。可重放：
