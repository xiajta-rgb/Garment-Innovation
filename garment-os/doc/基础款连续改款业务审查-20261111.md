# 基础款连续改款：业务问题与验证

本轮沿“选基础款 → 调领口/腰头 → 改袖/裤口/裤长 → 出裁剪清单 → 保存复用”查衔接问题。没有增加未经审查的服装轮廓。

## 已发现并修复

| 业务动作 | 原问题与影响 | 当前行为 |
| --- | --- | --- |
| 调好领口后选加长/收口短袖 | 整个构型被替换，领宽领深回到默认值；用户前一步设计丢失 | 袖片方案绑定装袖接口，只更新该部件声明的参数；保留领口和衣身 |
| 先改脚口，再改裤长 | 两方案互相写回默认值，无法叠加；臀部松量和腰头设置也会丢失 | 脚口方案只改脚口，裤长方案只改裤长；两种顺序得到相同参数、实际裁片和BOM版本 |
| 将当前T恤/基础裤带入款式工作流 | 工作流仅提供背心/开襟帽衫，当前基础款被默认改选背心 | 两种T恤和松紧腰基础裤已接通；进入时沿用当前方法和已修改参数，也可显式同步当前裁片 |
| 从基础裤导出技术草案 | 通用分支误加“包条端头工艺”提示，把背心工艺带到裤装 | 按实际源方法附加工艺待办；裤装保留自身腰头、松紧与装配缺口 |
| 缺少测量后确认结构 | 只提示“输入缺失”，用户无法知道补哪里 | 显示缺失/无效字段名称；从下身专用记录切到上装时明确缺胸围、肩端到腕等，不填演示值 |
| 在侧栏查看短T的“袖长” | 实际为人体肩端到腕，被误当成成品短袖长度 | 改标“人体肩端到腕”；短袖延伸仍在部件参数中管理 |

部件变化只在**同一基型**保留其余设置。跨方法切换会清除原方法参数。衬衫等完整构型方案仍按原有完整替换规则执行，防止遗留不适用的袖口、袖衩或袋片参数。

## 验证结果

- 完整检查：55个测试文件、1209项测试通过，架构边界、代码检查、类型检查和正式构建通过。
- 新增15项业务回归：实际组件点击、输入空值/越界、预览与应用、跨品类缺测量、撤销/重做、保存重开与导出。组件使用真实制图和编辑状态，文件下载由测试接收；没有浏览器操作或截图。
- 连续改款矩阵112组：两种T恤 × 男女样本 × XS–XXXL × 3种短袖变化，共84组；裤装 × 男女样本 × XS–XXXL × 两种应用顺序，共28组。逐一比较参数、前后身真实轮廓、源裁剪量和草案版本。
- 全库126组源裁片/毫米映射复核，25种结构方案的实际裁片离线图生成通过。
- 当前页面引用的正式后台模块共验证38个场景：全库30个场景，以及6个组合改款和2个无效输入场景；缺少后腰弧长、越界领深均被正确阻断。显示缓冲转移后原始毫米数据保留。
- 当前本地服务及5个关键模块返回HTTP 200。HTTP可访问性不等于页面交互或视觉验收。

本轮证据统一在 `doc/evidence/foundation-business-20261111/`，最终清单为 `verification.json`。`composition-matrix.json`保存112组结果；`business-scenarios.json`保存关键操作结果；三份`*-composed-workflow.json`与配套SVG为可审查范例。旧基础建设证据保留在foundation-blocks目录。

## 可审查范例

1. T恤先将前领深比例设为0.32、领宽比例设为0.28，再应用加长短袖。两项领口设置和前后衣身净样应保持一致，袖延伸比例应为0.7。
2. 基础裤先设臀围松量0.08、腰头高度比例0.04，再应用宽脚口和缩短裤腿。结果应同时保留四项：`seatEase=0.08`、`waistbandWidth=0.04`、`heelEase=0.3`、`lengthBonus=-0.1`。反过来应用得到同一份裁片。
3. 在上述组合基础上打开“款式工作流”，当前方法应保持T恤或基础裤。确认后应分别显示3种源裁片/4片、3种源裁片/5片；采购用量仍为待核定。
4. 保存组合，修改后撤销或重新打开。参数、裁片和BOM草案版本应一致。若清空短袖延伸比例再确认，应停止生成，不能拿旧输入继续出清单。

这些操作已做应用及组件回归；真实浏览器步骤和截图依用户此前安排稍后验收。

已打开检查本轮实际导出的组合图：[T恤组合裁片](evidence/foundation-business-20261111/t-shirt-composed-cad.png)、[基础裤组合裁片](evidence/foundation-business-20261111/elastic-waist-pants-composed-cad.png)。两图均由对应SVG离线转换，属于源图纸检查，不是页面截图；原SVG保留毫米坐标。

## 仍存在的业务缺口

胸贴袋和裤袋仍未接通，不能宣称已实现“加一个口袋”；落肩/插肩、独立领条净样、裤装成衣三维也待完成。组合可以随设计保存和恢复，但目前不能在资产库中新建“自定义命名结构方案”。面料物性、实际排料采购用量和制造工序仍需进一步接入。

本轮没有调用付费生图、没有写飞书，也未取得生产放行。三维仍是参考映射或示意，不是面料物理仿真。
