# 设计台与自动定制矩阵

> 后续整合：独立页面已撤下，以下为首版历史记录。当前矩阵位于原 GarmentOS 工作台工具栏，共享原模板库、尺寸、配色、款式与保存历史；`/` 恢复原工作台。最新交互与验证见[工作台矩阵模块整合](工作台矩阵模块整合-20261112.md)。下述独立模板库、单独尺寸/配色控件与首页默认短T不再适用。

首页恢复为用户的设计工作区，模板审查作为辅助入口保留。交互为：选基础模板 → 多选定制项 → 自动展开矩阵 → 点击方案查看三视图 → 加入选款夹 → 恢复继续定制或导出方案。未提交森灵生成任务。

## 一、设计台

- 左侧有全部14个模板，支持关键词与品类筛选；基础短T排在首位。公司原稿以4份参考稿入口保留，没有提升为同款毫米纸样。
- 中间展示当前方案的正、背、侧三视图及按定制生成的矩阵。横向比较可选领型、肩袖结构、版型、袖长或面料；其余选择组合为行，分页保持完整数量。
- 右侧每项可多选，默认常规/宽松×常规短袖/延伸短袖，共4款。全部选项组合共405款设计请求，不静默截断；每页最多3组，列数取决于横向维度的选择数。
- 支持主色与7个参考尺码，源裁片重新计算。三视图共用同一组裁片及比例，属于组装参考，不能当作试坯、垂坠或生产验收。
- 页面具有独立滚动区域；手机模板库可横滑，定制项在画布前，矩阵在自身区域横滑，页面不横向溢出。桌面滚动时定制项保持可见。

## 二、模板状态怎样影响交互

| 内容 | 当前行为 |
| --- | --- |
| 男士基础短T：圆领、标准装袖、平纹 | 常规/合体/宽松与3种源袖长参数组合可计算参考三视图；主体配缝继续使用既有检查 |
| V领、亨利领 | 枚举并可保存设计需求，显示领窝、领条/贴边和开口缺口，不绘制替代领型 |
| 插肩、落肩 | 枚举并可保存设计需求；插肩说明源版为连帽长袖且配缝超差，落肩说明缺身袖配套，不借用装袖 |
| 华夫格、坑条罗纹、珠地、竹节 | 枚举并可保存材料需求，未接组织显示与材料条件时不套用平纹三视图 |
| 其他源版模板 | 展示其自身毫米源裁片与问题，定制维度尚未接入，不沿用T恤参数 |
| 待重建或停用模板 | 显示实际缺口/停用状态，无替代几何 |

自动枚举的设计请求保留 `matrixEligible:false`、`productionApproved:false`。它不调用已暂停的旧矩阵生成器，也不恢复被撤下的装饰线图。旧接口继续阻断未配套设计图导出。全部模板的结构缺口见[全模板结构审查](全模板结构审查-20261112.md)。

## 三、选款与保存

设计台使用新的本地存储身份 `garment-os/design-desk/v1`，用户操作时保存，不覆盖旧矩阵或设计工作区数据。选款夹最多24款，每款独立保存定制项、尺码、颜色、结构需求和当时的配置。相同结构不同颜色/尺码的预览分别计算，不因结构编号相同而混用。

“继续定制”恢复该款的定制设定，不覆盖选款夹中的原款。JSON导出同时带上结构缺口和未获验收状态；重新读取时根据保存的设计请求重建配置，不信任文件中自带的几何或通过标记。

## 四、验证

软件检查63个测试文件、1255项测试通过，架构边界、代码检查与正式构建通过。新增6项应用检查覆盖实际组合映射、全部405项枚举、未配套结构阻断、矩阵重排、非法输入及保存后重建。

真实Edge浏览器13项流程检查通过，包括默认4款、实际袖片几何变化、颜色/尺码重算、同结构不同颜色/尺码的独立快照、刷新恢复、32款组合、缺口方案保存、翻页、模板搜索、其他模板独立裁片、继续定制、实际下载、手机双向滚动及旧链接兼容。模板审查页的20项浏览器回归也通过。结果为0页面异常、0生成提交。

另核查7个尺码×3种版型×3种袖长的63组完成态边界，固定比例0.44 px/mm下最大水平投影476.40px、最大高度314.12px，均在画框内。只平移压缩空白区域，保持各款同一比例，避免最长袖在画框内被裁切。边界记录为 `preview-frame-bounds.json`。

证据位于 [design-desk-20261112](evidence/design-desk-20261112/verification.json)：包含软件日志、浏览器逐项记录、实际导出文件、桌面默认/矩阵/选款截图，以及手机定制/三视图/矩阵滚动截图。软件和页面检查不改变模板的整款验收结论。
