# 改款元素组合

原设计台的主选择区已从模板裁片明细调整为按设计需求选择元素，保留现有工作台和公司稿三视图比例。

- 肩袖与领型：装袖、插肩、落肩，以及圆领、V领。插肩袖从领口延伸到袖口，衣身和袖片交界同步改变。
- 撞色：主色、袖片、领口、袖口独立设置，正背侧视图同步呈现。
- 口袋：无口袋、单胸贴袋、双胸贴袋；支持位置、尺寸和配色调整。
- Logo：文字标、字母框标、几何山形标和本地图片上传；支持正背侧放置、拖动、大小、文字、配色及复制删除。
- 面料：平纹、华夫格、坑条罗纹、珠地、竹节肌理示意；可查询企业面料，选择主体、领口或袖口并套用来源照片。

前后领圈等技术明细收进默认折叠的“制版参考 · 模板裁片明细”。三视图固定，结构部位按位置替换；口袋与Logo可以定位。复制方案保留完整改款元素且可独立编辑，保存重开、撤销重做及SVG/PNG导出同步保留这些元素。

企业面料照片嵌入方案后可随方案保存与导出。图片读取仅接受本次面料查询返回的来源记录；缺图时标为资料关联，读取失败时不标作已套料。实际验证选用 FC-00319“加厚26S精梳全棉平纹”，来源为 basedata.material.list，嵌入照片尺寸为768×544；这不代表已验证所有企业面料图片。

当前结构变化是设计视图，源CAD净样未自动改版。肌理为示意，照片的实物比例与颜色仍需核对。软件验证不等于专业制版批准，配缝、净样和样衣仍需审核。
