# 成衣边缘与细缝线修复

2026-11-11。本轮针对领口、袖口的像素阶梯，以及细缝线漏采样形成的零散黑点。提高边缘与细线的采样密度，减弱薄层自阴影；保留毫米几何和针距。

## 一、修改与效果

1. 显卡显示保留真实多重采样，并在普通屏幕上以两倍宽高绘制，使小于一像素的细线得到更稳定的覆盖。较大窗口限制绘制分辨率，减少额外显存开销。
2. 兼容显示改为按画面大小分配采样。在本轮 900 × 650 画面使用每像素 3 × 3 个独立深度样本，小画面最多 4 × 4；默认颜色、深度和输出缓冲预算保持不超过约 72 MB。CPU 绘制耗时会增加，未据此宣称交互帧率提升。
3. 仅主衣身参与阴影投射和接收。内层、边缘侧壁、罗纹、内折层和缝线继续接受灯光与深度遮挡，不参与粗粒度自阴影。主光阴影强度降为 0.35，减弱领口中的突兀黑块。
4. 源裁片、完成态网格、源 UV、针距以及相机均未变。两款模型的序列化指纹和所有相机参数逐组一致；没有扩大缝线实体或改画轮廓。

## 三、验证与边界

`npm run check` 通过：55 个测试文件、1,215 项测试，架构检查、代码检查、类型检查和正式构建通过。新增回归以四分之一像素宽黑线的实际面积覆盖作为独立预期，检查其移动到不同像素位置时不会完全消失；同时检查薄层阴影、真实深度遮挡和默认内存预算。

真实 Edge 浏览器完成 10 项成衣页面操作：三视图联动、工艺显隐与尺寸输入、前后款式稿、布厚与圆角、旋转、面料、上传贴图、切换兼容显示及返回裁片检查，页面错误为 0。[最终操作记录](evidence/garment-ui/2026-11-11T14-38-05-478Z/summary.json)。脚本等待输入框启用并用键盘替换数值；切换渲染方式前，先关闭会覆盖底部按钮的悬浮三视图。

本轮图证中，边缘阶梯、细线黑点及领口硬阴影已减轻。实际车缝仍按针距分段，整衣倍率下很细的针迹可能融合；放大视角仍可见部分结构折角。本轮不改变示意整形，不代表所有款式外观、材料、垂坠或生产验收通过。
