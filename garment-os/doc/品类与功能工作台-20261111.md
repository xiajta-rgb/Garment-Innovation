# 品类与功能工作台

本次把产品品类与裁片分类分开。裁片字典的22个大类、129个角色和13个使用场景，不能直接当作已经实现的整款服装。新增产品构型登记，每项明确必需角色、可选部件、关键尺寸口径、装配接口、整款模板、公司母版与缺口；鞋靴、包袋、无缝整织及防护认证不在本轮范围。

## 1. 页面与真实操作

顶部“品类与功能”入口按“模板与母版 → 版片与缝合 → 素材与工艺 → 三维与交付”组织功能。品类、接通程度及搜索共同驱动实际列表和详情。浏览分类不修改款式；明确选用模板才调用现有整款制图与检查。

各入口直接进入裁片生成器、配缝方向与裁片BOM、部件构型约束、三维裁片检查或成衣曲面示意。衬衫和拉链帽衫尚未接通整件三维，入口只允许进入三维裁片检查。不得静默换成T恤范例。独立角色参考直接携带角色与大类筛选。

资产库新增同一品类筛选，实际约束模板、结构组合、公司母版、面料和工艺卡片。尚未登记本品类用料时显示空结果。屏幕色可通用，仍不等同实物色卡。选用用料的具体目标公司母版始终在页头显示，浏览品类不会隐式替换该目标。

角色表分别列出整款方法的登记绑定、当前构型真正生成的源身份/裁片数量、其他设计的独立参考CAD与图示。数量未知保留待确认。角色齐备也不代表配缝、材料与工艺已合格。

## 2. 本轮审查结果

全部现存12个模板均有明确品类归属，其中7个可执行参考模板、4个待重建、1个停用。4个公司原稿母版各有独立归属。可执行模板身份与实际源制图输出逐项核对；三维支持判断与实际装配引擎共用一个能力定义。

可执行方法集中于上身基型、短T、收腰针织T、长袖针织上衣、包边背心、衬衫和拉链帽衫。其中前5类支持缝合曲面示意。圆领卫衣和套头交叉帽卫衣只有公司二维造型母版，不能借用Sven无罗纹长T或Huey拉链帽衫冒充整款CAD。

裤装、裙装、连衣裙、连体、内衣泳装、外套及配件等登记了明确构型与所需角色；已有的独立参考不会使其自动晋级为整款模板。Teagan/Sven独立领条缺口、Simon领面/领底未分身份也保持可见。逐品类清单见 [品类映射审查](evidence/category-workbench-20261111/品类映射审查.md)，机器可读清单见同目录coverage.json，也可在页面导出。

## 4. 可复核验收范例

1. 选择裤装，列表仅剩裤装构型；切换紧身裤显示前后裤片、松紧腰头、裆片及负松量/回弹要求。无整款方法时禁止启动生成和成衣三维。
2. 选择衬衫，明确选用Simon模板，进入实际配缝页；三维入口默认裁片检查。领面/领底缺独立身份仍显示待接入。
3. 选择套头交叉帽衫，只能打开AT25M3288公司母版，不会自动用Huey拉链帽衫替代。资产结构列表为空；切换拉链帽衫才显示4种同源结构方案。
4. 从短T进入面料页保留短T品类筛选，显示FC304及可候选复用FC-00332；实际应用目标母版另行显示。配色仍注明屏幕示意。
5. 导出的品类清单包含所有登记构型、角色依据、整款模板和明确缺口；生产批准为false，远端同步为not-performed。

自动化覆盖注册完整性、所有现有模板/公司母版归属、源身份与实际CAD输出一致、参考样本不能晋级整款模板、真实组件筛选、动作路由、禁用边界及导出数据。浏览器操作与截图按用户安排稍后进行，本轮不标记页面验收或生产验收通过。
