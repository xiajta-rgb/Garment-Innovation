# Logo与口袋编辑

原设计台中，新增口袋或Logo后自动选中。选中画布上的附件，可使用上方快捷栏缩小、放大、每次旋转15°，或点击删除。按Del删除当前附件，Esc取消选中。

画布四角手柄支持围绕中心等比例缩放，圆形手柄支持旋转；按住Shift旋转时以15°吸附。手柄随画布比例保持可点击尺寸。右侧保留具体宽高、位置与角度输入，Logo新增角度字段。文字、字母框标、几何图形与上传Logo均采用同一变换规则。

Del不会在输入框、文字编辑、选择框或弹窗中删除附件，也不会在比对模式删除元素。衣身、领口、袖子继续按固定部位替换，不添加附件的旋转手柄或Del删除行为。

Logo角度随方案保存，旧方案缺少角度字段时按0°显示。复制方案、撤销重做、保存重开、SVG及PNG导出保留Logo和口袋的尺寸、位置与角度，导出不包含编辑手柄。
