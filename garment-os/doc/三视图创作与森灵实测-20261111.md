# 三视图创作与森灵实测

默认工作区提供正、背、右侧二维创作。四份公司原稿母版保持不变，派生方案可组合领型、袖型、版型、衣长、口袋、下摆、拼色和图案；配色、面料与原有款式信息继续沿用。

三个快速方案为撞色口袋 Polo、宽短图案 T恤和拼色袋鼠帽衫。逐项修改会保留其他选择，支持撤销、重做、保存后重开；可下载 SVG、1680×900 PNG 和关联数据。图案当前是可切换位置的内置几何图案，尚无自定义图案上传。侧视为设计补充；这些改款未接入毫米制版，改款后裁片/三维入口会禁用。

## 使用

1. 选公司母版，再选快速方案或右侧改款选项。
2. 检查正、背、侧三图和配色，保存设计。
3. 点击“森灵测试”，选择模型和技术款式/面料效果。
4. 点击“将当前三视图送入森灵”。实际上传当前三视图 PNG，连同设计要求生成，默认模型为 nano-banana-pro。
5. 对照提交图和返回图，下载本次测试记录。记录包含原参考 PNG、当时设计、模型、要求与结果。

提交后继续编辑不会更改已提交方案，页面会提示结果对应旧方案。等待中和响应不明确时只能查询原任务，不自动再次出图。本地任务索引目前保留30分钟，服务重启会丢失；页面刷新也会丢失面板状态，离开前应下载测试记录。不要把重复点击或重启作为恢复未知任务的方法。

## 两组真实出图

通过实际编辑器分别提交两个不同方案，均收到森灵原图。输入图片哈希和返回的 inputSha256 一致，证明图片确实传入生成链路。每组只提交一次。

| 方案 | 实际结果 | 目视检查 |
| --- | --- | --- |
| 撞色口袋 Polo | 返回正背侧三图 | 深绿/米色、短袖、前胸袋保留；领口、袖形、下摆出现重新解释，增加面料文字。不是精确复刻。 |
| 拼色袋鼠帽衫 | 返回正背侧三图 | 连帽、长袖、侧拼色、袋鼠袋、罗纹下摆基本保留；侧面口袋与袖子关系需人工核对，细缝线有所省略。 |

测试图均作为设计候选，未作人工验收或生产批准。面料效果选项已接入要求，本轮真实出图只测试技术款式模式。

原始输入、原图、请求记录与同视角并排图见[实测对比](evidence/style-three-view-20261111/comparison.html)，任务证据见同目录 senling-live.json。截图来自本地编辑器，调用的是森灵 AIS 接口，不是森灵自由画板截图。

这两组请求使用的输入已单独冻结为 live-reference.png；后来修正袖口端点、后领和开衩表达后的编辑器截图单独保留，不替换已提交输入。

## 验证

真实浏览器检查覆盖三视图、组合改款、连续编辑、撤销重做、保存重开、帽衫方案、裁片边界提示、森灵入口和 PNG 下载。后端检查覆盖图片上传、图片哈希与任务身份、无效输入拒绝、响应不明确时不重复提交，以及 Windows 实际网络传输的 JSON/二进制内容。

完整检查与最终浏览器结果保存在同目录 check.log、browser.json、verification.json。它们仅证明所列功能，不证明所有改款组合的审美质量或 AI 输出的款式保真率。
