# 裁片分类全面审查与验收范例

审查结论：原有6大类不足以管理完整服装裁片。本轮已建立覆盖常见裁切缝制服装的22大类、129个管理角色、7种材料身份和13类服装场景，接通目录、筛选、源身份和检查门禁。**分类范围已扩充，不等于完整CAD库已建成。**

当前19种真实源身份只覆盖6大类、9个角色，其中1个是“领面 / 领底合并参考”管理身份，不能计为独立领面加独立领底。其余120个角色仅完成分类定义，没有接入生成器。本轮没有把这些定义画成示意裁片。

## 三、统一分类语义

1. 六个筛选轴独立：结构大类、具体角色、结构层级、材料身份、对折方式、裁剪数量。绘图图层另行管理。组内多选为“或”，不同轴之间为“且”。
2. 材料身份包括面料、里料、衬料、垫衬/衬底、保温填充、衬垫、罗纹。“腰头里片”是结构角色，“里料”是材料；两者不能互相替代。相同角色的不同材料层也不能默认同形。
3. 裁2片不推断镜像；对折不推断数量。3片、6片、13片等合法数量有明确标签；未声明或非法值保留未知。数量超过12使用“其他已知数量”筛选，实际数量仍保存在源记录中。
4. 省道、褶量、连身门襟、连身驳领、折边属于母片特征；剪口、布纹、钻孔、净线和毛线属于图纸层。不会为这些特征虚构额外裁片。
5. 买入纽扣、拉链、织带、松紧带、模杯、钢圈、肩垫、标签等归BOM；只有实际裁切的形状进入裁片库。整织袜和整织领不伪装二维裁片。
6. 同一源裁片的每条路径必须共用角色、大类、材料、版本、数量和裁法。缺失或冲突阻断参考预览；即使角色本身合法，错绑到另一个源身份也不能通过。
7. 未知筛选条件匹配空集并提示清除，不再错误地显示全部。已删除只凭部位名称推断具体角色和裁法的旧兼容函数。

Simon过肩改归独立过肩大类；领座与领面/领底合并参考分开；袖衩内外搭分别登记，不再都只依赖“袖部”标签。快照中的旧部位标签仍保留为历史输入；新关联是本地交叉映射，不能当作远端标签已经更新。

源裁剪清单中出现“衬料2片”，只证明存在衬料裁剪指令。尚未生成独立衬料几何时，筛选“衬料”必须为空，不复制面料轮廓冒充衬料。领底同理：源中的虚线参考不等于独立闭合领底片。

5. 选择“领底 → 查看当前裁片”：QC、总览、画布及生成器必须撤回上一片图形，显示空结果。禁止保留领面图形冒充领底。
