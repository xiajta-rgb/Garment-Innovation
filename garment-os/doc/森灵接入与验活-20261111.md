# 森灵 AIS 接入与验活

入口：款式工作流 → 企划设计稿 → 森灵 / 图稿解析试验。

1. 选择生图模型，填写参考稿描述，或使用背心示例，点击“生成参考稿”。
2. 检查图片后点击“用作参考设计稿”。选择识图模型，点击“提取结构候选”。
3. 核对候选，点击“将观察填入结构选择”；检查当前测量数据，点击“确认设计并生成裁片”。BOM 和技术稿沿用同一 CAD 版本。

现阶段识图只接收已定义的包边背心及开襟连帽卫衣。可见结构不足时应返回空候选。观察合同拒绝测量、几何及放行字段。图稿不参与计算毫米数值；本机上传图仅在浏览器预览。联动 JSON 记录已选用参考稿的服务、任务号、模型与被采用的观察，不带临时图片链接。

## 连接与部署

当前本机沿用 Amazon-image 的森灵 AIS 账号，直接调用森灵接口，不依赖另一个应用的进程。MCP 服务握手成功，但当前 MCP 凭据没有任务查询权限，因此 GarmentOS 使用已实测的 AIS 路径。未更改 Amazon-image 的代码、配置或数据。

换机时可在启动 GarmentOS 前向服务端注入 `AIS_USERNAME` 和 `AIS_PASSWORD`，或者在本机忽略文件 `.env.local` 中设置 `GARMENTOS_AIS_ENV_FILE`，指向已获授权的 Amazon-image 根目录 `.env` 绝对路径。凭据不进入前端。接口随 `npm run dev` 或本地 `npm run preview` 提供，纯静态发布不包含此服务。任务查询记录保存在本地服务进程内，30 分钟过期，重启后不可在页面续查。网络响应不明时可查询同一任务，服务不会自动重新提交生成。
