## 一、设计维度

| 层次 | 可组合的设计选项 |
| --- | --- |
| 领型 | 罗纹圆领、V领、三扣亨利领、小高领 |
| 肩袖结构 | 标准装袖、落肩装袖、插肩袖 |
| 廓形 | 经典直身、宽短箱型、宽大廓形 |
| 面料组织 | 平纹汗布、华夫格、坑条罗纹、珠地、竹节肌理 |
| 袖型 | 常规短袖、及肘袖、翻折袖口 |
| 下摆 | 平直双针、侧开叉、弧形下摆 |
| 拼色 | 同色净面、按肩袖结构撞色、身侧拼片 |
| 胸袋 | 无袋、方底、尖底、圆角单胸袋 |

默认矩阵纵向是三种肩袖结构，横向可切换领型、面料组织、廓形、袖型、下摆或拼色，每组9个方案。其余已选设计保持一致，方便辨认当前维度的影响。侧栏可自由组合更多选项，包括不在九宫格横向三列中的小高领、珠地、竹节组织及袋型。

六个设计方向提供连贯的起点：都市基础、运动插肩、松弛落肩、华夫肌理、罗纹V领、珠地箱型。它们实际改变结构、组织、配色和比例，随后仍可独立调整。这些方向不等于生产系列，也不按理论排列组合数宣称已开发款数。

## 二、技术款式图

本页改用连续矢量平面图，分层绘制外轮廓、结构缝线、双针卷边、门襟、袖口、领条与组织示意。正背侧共享同一份设计设定及成品规格提案。

- V领改变前领窝与领条轮廓，增加前中领条拼接；后领保持后领结构。
- 亨利领前面显示门襟与三粒扣，背面没有虚构扣件。
- 插肩缝从领口延伸至腋下，不保留普通装袖的肩缝和袖窿线；落肩改变肩端位置、肩斜位置与袖窿深度。
- 箱型同时加宽减长；宽大廓形增加围度与衣长，避免只改标签。
- 华夫格、坑条罗纹、珠地、竹节使用不同的矢量组织符号，正背侧同步。可关闭“面料组织”检查净线稿，轮廓与结构不变。
- 侧开叉、翻折袖口、弧形摆分别有对应的结构图形。右侧视图为结构补充，不代表已验证的人体厚度或实物垂坠。

矩阵以前视主图搭配背面、侧面缩图；放大后并排查看完整三视图与结构组成。图片导出保留SVG原始宽高比例，修复此前固定1680×900画布导致的拉伸。

## 三、设计选款

点选方案后，可继续组合结构、面料组织、廓形与工艺细节，再加入选款夹。相同完整设计不会重复加入，最多24款。已选记录保存当时的全部设定，后续改款不覆盖；可指定最多4款并排查看12个视图。

“以此组合继续展开矩阵”保留当前设计，再切换另一个维度。更换参考尺码保留当前微调方案的结构、组织与配色。界面自动保存于浏览器；支持下载技术三视图SVG、PNG、结构设计规格JSON及选款JSON。

新记录使用独立的v2存储，不覆盖此前的毫米参数矩阵。旧版与原选款仍可通过 <http://localhost:5341/?workspace=matrix-v1> 查看。两版不把不同语义的数据强行合并，也不声称跨设备同步。

## 四、设计与制版边界

当前新图是**技术款式设计方案**。人体参考源仍是FreeSewing男体样本；胸宽、衣长、袖长与侧厚是本轮成品设计提案，不能冒称已复核的成品尺寸或裁剪尺寸。

V领、亨利领、小高领、落肩、插肩、箱型和拼片等新结构尚未完成裁片配缝验证。设计导出明确记录`drafting-validation-pending`，不提供这些方案的已配套纸样导出。“基础裁片”入口单独保留原Teagan工作台，不能把原装袖圆领纸样当作当前所有新结构的纸样。

组织名称与图案用于表达肌理方向；成分、克重与组织密度保持未知。渲染图案的间距不是材料针距、密度或物性实测值。所有方案均未生产批准。
