# 开源制版引擎调研结论 (2026-11-08)

> 历史调研记录。下列迁移设想及“工业级/保证/标准尺码”措辞不能作为当前验收依据；当前实际采用完整的 Brian/Teagan/Sven/Simon 4.10.2 制图，并保留明确生产缺口。最新状态见[全模板审查与重建报告](全模板审查与重建报告-20261110.md)。

## 结论: 采用 @freesewing/core (MIT, v4.10.2) 作为制版几何内核

## 调研对象
| 项目 | 语言 | 许可 | 评估 |
|---|---|---|---|
| FreeSewing core | TS/JS (bezier-js) | MIT | ★★★★★ ESM 原生, 与 React 栈同构, Point/Path/Part 模型, 真曲线 offset/join/divide/edge, Svg 渲染器 |
| Seamly2D (原 Valentina) | C++/Qt | GPL | ★★★★ 桌面 CAD 功能全, 但 C++ 无法进 Web 栈, 仅可借鉴公式 |
| 手搓 geometry.ts | TS | - | ★★ 已到瓶颈: 缝份角/曲线偏移/光滑连接均无法达到工业级 |

## PoC 验证 (scripts/freesewing-poc.mjs, 5/5)
- 真领口曲线 (贝塞尔) offset 30mm: 74 采样点中位距离 = 30.0mm (等距精确)
- 偏移外口自动角部处理, 无丢角/无折叠/无 NaN
- 袖山圆顶 cubic + 20mm 缝份偏移 ✓

## 分工边界 (不自研的部分 vs 保留的部分)
### 用 FreeSewing 替换 (几何内核)
- Point/Line/Curve 构造与求交
- 缝份 offset (角部/等距全部由 bezier-js 保证)
- 轮廓闭合/逆行/拼接 (join/reverse/edge)
- SVG 渲染 (Svg 类)

### 保留自研 (我们的业务价值, 不与 FS 重叠)
- 人体测量值体系 (ASTM/GB 尺码表, 17 项)
- 制版公式 (Aldrich 衣身/袖山比例) — 作为 FS 的公式输入
- 约束校验引擎 (11 条工业规则)
- 裁片 QC 门禁 / 标签体系 / 完整尺寸规格表 / BOM 用料
- 生成器确定性生成 / 推档 / 飞书元素库同步

## 迁移路径 (三步)
1. DraftingAdapter: draftBodice/draftSleeve 内部改用 FS Point/Path 产出轮廓 (保持现有 Block 接口不变)
2. 缝份: segmentedSeamAllowancePath → Path.offset 按边角色偏移
3. 删除手搓 offsetPolygon/flatten 采样补偿代码
