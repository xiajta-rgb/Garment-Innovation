# 成衣示意与三视图联动

本轮按用户“示意图大体自然，并与二维三视图对应”的要求整改。当前结果是可旋转、可贴图的成衣技术示意；没有以显示平滑替代物理垂坠或制造验收。

后续已读取研发货盘真实设计稿，新增放大前后款式稿、分层线条与同源工艺引线。当前对照与验证以[研发设计稿整改](研发设计稿对照与款式稿整改-20261111.md)及`rd-design-alignment-20261111`证据目录为准。

## 一、当前行为

顶部“3D 映射”默认进入成衣。Brian、Teagan两款及Sven使用同一生成路径：净样、源弧长配缝、示意整形、显示细分与布厚、工艺几何、材质。Aaron衣身也使用该路径，但没有冒充已完成其领口/袖窿包条。Simon和Huey成衣组装仍明确提示未接通。

- 开口身份取自源CAD的领窝、衣身下摆、袖口和袖窿边界，记录源片、净边、展开次数、精确源弧长及顶点路径。
- 通过低频轮廓整形和跨缝共享点平滑，消除不自然的高频尖折；不改二维净样、源UV和源配缝模型。下摆附近保留线性高度场，避免不规则网格细分将双针变成波浪线。
- 独立领条有内外面、封闭侧壁、连续环绕坐标及轻微罗纹起伏。领圈采用共同平面和连续切线生成方向，避免肩颈处随衣身法线突然翻转。首尾几何逐点相等、UV保留独立接头。
- 袖口/下摆有内折实体与双针线迹；肩缝与装袖线迹从源配缝路径生成。每道工艺合并成一个网格，不为每针创建一个绘制对象。
- 开关会真正移除/恢复工艺几何。衣身贴图不覆盖领条和线迹的独立材质。旋转、换色或换图不重新生成CAD。

## 二、三视图和源二维的区别

二维正、背、侧图直接正投影当前完成态网格，统一比例尺、方向和遮挡规则，并显示相同的领条、折线与缝线。点击图同步主视角，导出SVG保留工艺身份。源二维裁片仍用于尺寸、制版与追溯，三视图不能作为裁剪轮廓。

三维拾取仍通过三角形重心坐标反查源二维毫米。领条使用独立裁片坐标；线迹和折边层的坐标是沿工艺路径的参数，导出为`_PATH2D`，没有伪称衣身CAD。glTF中的`qualityAppliesTo`指向源配缝试验，示意整形位移另存。

## 三、可编辑工艺范例

| 参数 | 默认设计值 | 关联逻辑 |
|---|---:|---|
| 罗纹领成品宽 | 18mm | 改变三维领条宽与裁片草案宽 |
| 领条净长比例 | 0.90 | 源完整领窝弧长乘该比例；实际可行性待面料伸长/回复测试 |
| 领条缝份 | 6mm | 裁剪长=净圈长+两端缝份；裁剪宽=2×(成品宽+缝份) |
| 下摆/袖口折深 | 25/20mm | 内折层与双针位置共用该值 |
| 双针间距 | 4mm | 两道针位分别距开口“折深−3”和“折深−3−间距” |
| 线迹针距 | 3mm | 控制实际线段数量与间隔 |

领条以后中接头为起点，提供四等分剪口、对折线、净线与毛线。上述公式是当前示例的设计合同，不代表任意面料的通用生产标准；领条草案的材料ID保留空值，未自动发布到正式BOM或飞书。参数是会话预览设置，可通过草案导出保存。

## 五、精度和性能边界

示意整形相对原配缝模型在当前男M样本最大移动约Brian24.4mm、短袖22.5mm。之后的显示细分限制是相对整形网格，不能将其2mm限制误报为总精度。默认完整几何约9.5万三角面，当前主机整形成衣与工艺派生约0.5秒；这是离线CPU测量，不等于页面延时或GPU帧率。几何按源对象/设置缓存，三视图按模型缓存，旋转不重建。

成衣兼容视图使用Canvas2D呈现CPU逐像素深度缓冲、插值法线与源毫米UV贴图，不再用三角面平均深度排序，消除薄内折层穿绘形成的碎面。沿用旋转、平移、缩放和拾取；切换渲染器更换画布，避免同一画布已绑定WebGL后无法取得2D上下文。软件模式限制约90万像素、贴图解码最长边1024px，不受三角形DOM数量拖累；静止不重绘，相机输入合并到下一帧。它与硬件视口有不同灯光和纹理过滤，性能及实页外观仍待浏览器验收。
