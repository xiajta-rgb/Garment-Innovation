# 款式工作流 · 设计稿到裁片

本地入口：`http://localhost:5341/` → 画布上方“款式工作流”。

1. **企划设计稿**：可选本地参考图，人工核对结构。目前开放包边背心的前领口下降比例，以及开襟卫衣的前贴袋与罗纹开关。使用工作区已有的体型、尺码与测量值，尚未核验实测来源。缺头围或参数越界会阻断，当前工作区不会被部分覆盖。
2. **裁片映射**：确认后调用现有整套参考制版与结构门禁。页面绘制同一工作区的源净样、裁边与源标记线；可撤销。改动结构或工作区尺寸会撤下旧工作流输出。已确认的制版输入可使用原有“Save”保存；上传图和观察文件只留在此会话。
3. **BOM 草案**：用通过检查的实际裁剪指令列出源裁片、材料角色、对折和裁剪片数。商品货号与采购用量保持 `null`；未把几何长度充当采购用量。
4. **技术与工艺稿**：复用已定位的源尺寸、构造关系与待复核事项。导出的 JSON 包含制版输入、CAD 毫米路径、裁剪清单和构造资料；整幅参考裁片 SVG 与 JSON 使用同一个修订标识。成衣正背技术稿和制造工艺单待接入。所有输出均为参考草案。

## 森灵与图稿解析试验

页面保留独立入口，并提供可下载的 `garment-os/style-observation/v1` 示例。当前接收结构观察 JSON：背心可观察款式，卫衣可观察款式、前贴袋和罗纹是否存在。不接收尺寸、曲线或生产状态；不能确定的观察不得自动填成“无”。导入后先选择是否填入，再由用户确认制版。

后续可把森灵的图作为参考，并将图稿解析结果写成同一观察格式。建议用同款不同领口、口袋与罗纹的带标签样本检查识别，再逐项比对制版输出。本次没有连接森灵、上传图像、执行识别、写入飞书或发布生产数据。

验证覆盖：页面入口、结构确认到真实源路径、联动草案导出、观察与确认的隔离、缺量/越界拦截、旧稿撤下、撤销及切换设计隔离。已有真实浏览器脚本加入工作流步骤；当前 Work 禁用本地浏览器，本轮未跑页面截图。
