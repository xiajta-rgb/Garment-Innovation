# 自由裁片组合工作台

> 历史版本说明：结构裁片自由移动的交互已被用户要求的新规则取代。当前行为见《固定三视图部位替换-20261112.md》；本文件和原证据保留用于对照。

裁片组合设计的默认入口改为可编辑的三视图画布，并与原左侧模板管理库联动。原配套短T参数及配缝页通过“配套尺寸与配缝”进入。

## 操作流程

1. 点击左侧模板，画布上方显示该模板的可选裁片。点击裁片加入当前视图，或拖放到正、背、侧面。
2. 选择已加入的裁片，拖动调整位置，通过右下角手柄缩放；按 Shift 等比缩放，方向键微调。
3. 右侧可输入宽高、位置、旋转角度，调整颜色、镜像、显示、图层顺序，复制或删除单片。
4. “复制改款”保留原方案并生成独立副本；“并排比对”使用相同视角与缩放比较方案，支持切换正背侧面。
5. 顶部 Save 保存方案、来源和裁片调整；支持撤销、重做、New 后通过 List 重开。编辑画布可导出 SVG、PNG。

## 资源及数据

- 9个已开放参考模板均能提供裁片：Paco、Sandy、Aaron、Huey、Brian、Teagan直身与收腰、Sven、Simon。
- 短T提供按公司稿指导比例绘制的款式片，已有比例不变，可一键放置11个独立部件形成三视图。保留其对应毫米参考净样；其它模板先使用真实源净样作为组合素材。
- 每片冻结自己的模板、尺码、测量、松量及构型输入。切换左侧模板、调整新加入片的来源，不覆盖画布已有片。
- 宽高字段按对应源净样定义并以相同比例改变显示尺寸。位置为画布坐标；款式图比例不宣称是公司同款毫米纸样。
- 自由组合及非等比缩放不改变源CAD路径，也不会产生配缝通过结论。跨模板、改尺寸后的方案保留“配缝待核对”。
- 读取和保存时校验来源身份、模板状态、测量缺失、尺寸范围、重复标识、方案与裁片数量。
