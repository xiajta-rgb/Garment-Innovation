# 固定三视图与部位替换

后续更新：主选择区已升级为[改款元素组合](改款元素组合-20261112.md)，加入肩袖结构、撞色、Logo和企业面料；结构位置继续固定，口袋与Logo允许定位。以下保留本阶段的交互与验证记录。

本轮按用户要求修正原工作台的裁片交互。正面、背面、侧面保持固定位置；衣身、袖子、领圈属于固定结构部位。只有明确归类为贴袋的附件允许自由定位。

- 点击模板中的结构裁片，替换对应部位；袖子同步处理正背面左右袖及已有侧面映射，领圈同步处理正背面。
- 重复替换保留原部位标识、配色、显示状态及层叠顺序，不叠加同位袖子或领圈。
- 固定结构件取消拖动、方向键移动、位置与角度输入、任意换视图、镜像及复制入口。宽高与配色继续可调。
- 调整袖片尺寸时保留肩部连接锚点；恢复源尺寸不会破坏左袖方向。衣身与领圈保留领口中心位置。
- 口袋保留拖动、方向键、缩放、旋转、换视图、复制与层级调整。
- 旧方案在安装、读取和保存时重算结构件的固定位置与零旋转；口袋定位、原有尺寸及方案内容保留。
- 只有源净样而没有成衣款式映射的模板仍可在库中查看，但标明“待款式映射”，不可将展开净样直接替换到成衣三视图。

这些是设计视图的定位和替换规则，不能代替尺寸改款后的配缝、制版及样衣审核。当前接通的成衣款式映射仍以已有公司稿比例的短T为基础。
