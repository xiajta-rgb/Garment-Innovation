# 部件组合与构造规则验收范例

本次把“待定义”拆成可执行的设计参数、可计算的构造规则、需要补录的工艺/材料数据，以及仍需实现的完成态几何。定义一条规则不等于该接口已经匹配。当前仍未获得完整装配放行，不将参考图称作生产成品。

## 一、可以实际操作的组合

打开 http://localhost:5341/ ，选“衬衫”中的完整 Simon 模板，进入“裁片库 → 部件组合”。

- 袖型：长袖配袖口和两种袖衩；短袖配源镜像折边。切换短袖后，实际裁片从10种变为7种，袖口及两种袖衩从图形、清单、配接关系中同时移除。
- 袖口：斜角、圆角、直角三种双层单翻袖口。法式双翻未建立独立合同，不能通过导入绕过。
- 下摆：平下摆、圆弧下摆、侧开衩下摆。前后身同时重算，保持侧缝与用途检查。
- 领部：可调领尖方向角、外展角、弯曲、领座宽和弯折等。修改后重新生成完整模板，不拼接不同来源的SVG。

数值编辑后按 Enter 或移出输入框才应用，允许先清空和输入小数。越界值明确报错并保留上次有效组合；在源允许范围内但几何未通过的输入，会撤回图形并显示失败原因。参数范围不是任意参数交叉组合的制造保证。

“部件组合”中的分类按钮同时筛选构造卡片和所需输入定义。裁片标签筛选仍在原有生成器/组成页控制实际裁片显示。

| 袖型 | 长袖 | 长袖、短袖 | 决定袖片构型及袖口/袖衩存在性 |
| 袖口造型 | 斜角 | 斜角、圆角、直角 | 仅长袖；面料4片、衬2片，双层不重复计算缝长 |
| 下摆造型 | 平摆 | 平摆、圆弧、侧开衩 | 前后身同源重算 |
| 领围松量比例 | 0.02 | 0–0.10 | 领座目标长＝颈围×(1＋松量) |
| 领尖角 | 85° | 60–130° | 源领尖方向线角度，非领尖内角 |
| 领面弯曲比例 | 0.035 | 0–0.10 | 端部下移量相对领长 |
| 领外展角 | 3.5° | 0–10° | 领上边方向角 |
| 领面端部留空比例 | 0.025 | 0–0.06 | 两端总设计留空＝颈围×本值 |
| 领底缩减比例 | 0.03 | 0–0.06 | 源领底差异量＝领面后中宽×本值 |
| 领面宽倍率 | 1.2 | 0.9–2 | 领面中心宽相对领座宽，另含领底缩减比例 |
| 领座弯折角 | 3° | 0–5° | 源中心线弯折 |

| 短袖长度比例 | 0.40 | 0.20–1 | 仅短袖；受源袖山高与折边最低长度约束 |
| 短袖折边比例 | 0.04 | 0.01–0.20 | 仅短袖；保留源镜像折返轮廓和折线 |

## 三、完成态规则与真实缺口

| 接口 | 已沉淀的可计算规则 | 当前限制 |
| --- | --- | --- |
| 领面接领座 | 目标＝颈围×(1＋领围松量−留空比例)；分别输出源领面实长、目标残差、每端留空和扣除留空后的领座差值 | 领座上边仍需按独立弧长定位起止剪口，不能按领面实长反向截出同长区间 |
| 领窝接领座 | 目标＝颈围×(1＋领围松量)；原始前后领窝与领座下边分别积分 | 需门襟翻折后的真实装领端点；搭门不能视为领窝吃势 |
| 独立领底 | 源差异量＝领面后中宽×领底缩减比例；保留实际源参考线 | 参考线仍未成为独立闭合、带缝份和用料身份的裁片 |
| 袖口与褶 | 单袖去褶平面基准＝源袖下口实长−源褶口实收量；源折线须位于收量中点；两袖单独计算 | 袖片基础宽使用加法，袖口宽使用乘法；默认M码去褶后仍相差约−4.300 mm，标记“需重制接口”；还需袖衩折返完成态 |
| 袖衩外搭 | L＝肩端到腕×长度比例；W＝腕围×宽比例；塔尖纵向位置L＋1.5W，第三折线y＝1.5W | 长度相等不放行；仍需切口端转角、车缝偏移、折返后装袖端点与布纹 |
| 袖衩内搭 | w＝min(W/2,10 mm)；两折线y＝±w，外缘y＝±(2w−1.5 mm) | 同样需完成态、转角及材料方向，不重复消耗切口外侧 |
| 短袖折边 | 深度＝肩端到腕×短袖折边比例；展示源折线与镜像轮廓 | 尺寸已定义，缝型与厚度条件仍未确定 |
| 针织领条 | 净条长＝完成领窝长×(1−设计缩率)；毛长另加两端接缝；毛宽＝2×成品宽＋两道装领缝份 | 未录设计缩率与对应材料伸长/回复条件；尚未生成独立领条，不默认使用15%缩率 |
| 衣身/基础袖折边 | 区分净样、毛样、折线与车缝线；单折/双折/包边分别定义 | 需折深、缝线边距、曲线翻折差量和厚度条件；不把基础10 mm缝份当任意折深 |

源点、褶线、塔尖、搭片长度和袖口源尺寸也参与检查。缺点、褶线偏移、缺折线路径、塔尖偏移或伪造袖口长度会拒绝构造报告，不能只更新说明文本。

## 四、27项工艺与材料字段

这些字段已具备稳定编码、数据类型、单位、归属层次、适用条件、校验要求及证据要求。数据字典随验收记录导出；当前未建设其完整录入与工艺几何执行模块，值一律为空，不能当作已经有材料事实。

| 组别 | 已定义字段 |
| --- | --- |
| 材料事实与测试条件（13项） | 材料实体与版本、方向、厚度、可用门幅、纵向缩水、横向缩水、指定方向伸长率、测试负荷、试样宽度、测试方法/条件、加载停留时间、卸载回复时间、残余伸长率 |
| 接缝（1项） | 每组接口的接缝/缝型、针距和层次定义 |
| 领口（5项） | 收边构型、领条成品宽、设计缩率、条端接缝份、装领缝份 |
| 下摆（4项） | 折边方式、首折深度、次折深度、车缝边距 |
| 袖与袖衩（3项） | 基础袖折深、袖折边缝线边距、袖衩固定缝线边距 |
| 袖口（1项） | 面/里层翻折容位，不得用作消除接口差值的自由补差 |

不同来源不得混填：人体量、设计量、工艺量和材料实测各自有明确语义。缩水率可为负值表示增长；伸长率必须带负荷、试样宽度、方向和读取时间。领条设计缩率与材料伸长率不同：所需装领伸长＝缩率/(1−缩率)。

本轮没有向飞书写入这些字段或建立新表。现有元素库快照及稳定来源编码继续保留；本地构造字典不能冒充已完成的远端同步。
